§25.1平稳、AR(1) 与单位根

AR(1)：x_t = φx_{t−1} + ε_t。当 |φ|<1 时平稳，

E[x]=0 , Var(x)=σ²/(1−φ²) , ρ_k = φ^k ; φ=1 即随机游走，Var(x_t)=tσ²

单位根过程差分后平稳（I(1)→I(0)）；ADF 检验本质是检验差分方程里 x_{t−1} 的系数是否为 0，但其临界值非标准，不能直接套 t 分布。把趋势当成水平、或把水平当趋势，是宏观实证最常见的错误。

§25.2伪回归：共同趋势制造的虚假显著

Granger–Newbold 的经典结果：两条相互独立的随机游走做回归，R² 与 t 值往往很大，且 t 值随样本量增大而发散，因为残差本身非平稳，通常的 t 检验前提被破坏。判断办法：

检查期望结果若不满足
残差是否平稳ADF 拒绝单位根 / DW 不接近 0可能是伪回归
加趋势项后系数仍稳定系数由共同趋势驱动
差分后再回归关系应消失说明原关系是伪的

脚本用数百次重复抽样把「假阳性率远超 5%」量化出来，比任何一句「相关不等于因果」都更有说服力。

§25.3协整：非平稳但存在长期均衡

若 y_t 与 x_t 都是 I(1)，但存在 β 使 y_t − βx_t 平稳，则称二者协整。此时水平回归不是伪回归，且可用误差修正模型同时刻画长期均衡与短期调整：

Δy_t = α(y_{t−1} − βx_{t−1}) + γΔx_t + ε_t , α<0 表示向均衡回调

这是 第 19 章 · 开放经济：国际收支、汇率与三元悖论 的 PPP、第 17 章 · 货币政策、通胀与利率：费雪方程与泰勒规则 的利率期限关系与 第 28 章 · CAPM 与因子模型：什么风险该有补偿 因子回归在实证中的标准处理流程：先判单整阶数 → 再判协整 → 最后定动态模型。

§Python 建模实例

AR(1)、随机游走、伪回归与协整残差

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 25-timeseries.py | 平稳性与伪回归蒙特卡洛（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
T, REPS = 200, 400
PHI = 0.8
SIGMA = 1.0
BETA_COINT = 2.0

def mean(v):
    return statistics.fmean(v)

def lag1_corr(v):
    a, b = v[:-1], v[1:]
    ma, mb = mean(a), mean(b)
    num = sum((a[i] - ma) * (b[i] - mb) for i in range(len(a)))
    den = math.sqrt(sum((x - ma) ** 2 for x in a) * sum((x - mb) ** 2 for x in b))
    return num / den

def ols1(xs, ys):
    mx, my = mean(xs), mean(ys)
    sxx = sum((x - mx) ** 2 for x in xs)
    b = sum((xs[i] - mx) * (ys[i] - my) for i in range(len(xs))) / sxx
    a = my - b * mx
    e = [ys[i] - a - b * xs[i] for i in range(len(xs))]
    s2 = sum(v * v for v in e) / (len(xs) - 2)
    se = math.sqrt(s2 / sxx)
    tss = sum((y - my) ** 2 for y in ys)
    r2 = 1 - sum(v * v for v in e) / tss
    return b, b / se, r2, e

def random_walk(rng, t):
    v, out = 0.0, []
    for _ in range(t):
        v += rng.gauss(0, SIGMA)
        out.append(v)
    return out
# ---- 平稳 AR(1) ----
rng = random.Random(7)
x, ar = 0.0, []
for _ in range(10000):
    x = PHI * x + rng.gauss(0, SIGMA)
    ar.append(x)
# ---- 伪回归蒙特卡洛 ----
mc = random.Random(23)
false_pos, r2_list = 0, []
for _ in range(REPS):
    xx, yy = random_walk(mc, T), random_walk(mc, T)
    b, t, r2, e = ols1(xx, yy)
    if abs(t) > 1.96:
        false_pos += 1
    r2_list.append(r2)
# ---- 协整：y = 2x + 平稳噪声 ----
coint = random.Random(31)
xc, yc = 0.0, []
xc_path = []
for _ in range(T):
    xc += coint.gauss(0, SIGMA)
    xc_path.append(xc)
    yc.append(BETA_COINT * xc + coint.gauss(0, 0.5))
_, _, _, ec = ols1(xc_path, yc)
# ---- 数值验证：打印可手算核对的量 ----
print("AR(1): 理论方差=%.4f 样本方差=%.4f" %
      (SIGMA ** 2 / (1 - PHI ** 2), statistics.pvariance(ar)))
print("AR(1): 理论 lag1 自相关=%.4f 样本=%.4f" % (PHI, lag1_corr(ar)))
print("伪回归 %d 次(两条独立随机游走): |t|>1.96 比例=%.4f 平均 R²=%.4f" %
      (REPS, false_pos / REPS, mean(r2_list)))
print("协整回归残差 lag1 自相关=%.4f (平稳残差应远小于 1)" % lag1_corr(ec))
print("对照: 水平序列自相关≈%.4f" % lag1_corr(yc))

操作：把回归改成对两条序列先做一阶差分再 OLS，观察伪回归的假阳性率是否回到 0.05 附近。　预期与判读：AR(1) 理论方差≈2.778、样本≈2.67，lag1 自相关≈0.79；400 次伪回归的 |t|>1.96 比例≈0.825、平均 R²≈0.225（两条序列其实完全独立）；协整回归残差 lag1 自相关≈−0.01，而原水平序列≈0.99。

改参数看趋势：PHI 越接近 1，AR(1) 方差越大；T 越大伪回归假阳性越严重；REPS 控制蒙特卡洛精度。　文件位置：part4/25-time-series/code/25-timeseries.py

§常见误区

  • 对非平稳水平序列直接套 t 检验：残差非平稳时标准 t 分布失效。
  • 把高 R² 当成关系存在的证据：伪回归能给出很高 R²。
  • 见到两条序列同向就断言协整：需检验残差是否平稳。
