给程序员的翻译

工具变量是一次「天然 A/B 实验的外生分流器」：z 随机改变 x，但不直接改 y；2SLS 就是先只用 z 预测 x（去掉与误差相关的部分），再用预测值回归 y。

§23.1内生性偏误

设真模型 y = β₀ + β₁x + β₂w + u，但回归里漏掉 w：

plim β̂₁(OLS) = β₁ + β₂·Cov(x,w)/Var(x) (遗漏变量偏误)

三种常见来源：遗漏变量、 simultaneity（y 反过来影响 x）、度量误差（衰减偏误）。第 20 章 · 识别：从数据生成过程到因果参数 的自我选择就是遗漏「能力」这一特例。加大样本不会消除偏误，只会把错误的数估得更精确——这是程序员常犯的「堆数据」直觉错误。

§23.2IV 与 2SLS

工具 z 需满足：相关性 Cov(z,x)≠0、排他性 Cov(z,u)=0（z 只通过 x 影响 y）。恰识别时：

β̂_IV = Cov(z,y)/Cov(z,x) = β₁ + Cov(z,u)/Cov(z,x)

2SLS：第一阶段 x = π₀ + π₁z + v 得 x̂；第二阶段用 x̂ 回归 y。由于 x̂ 只由 z 构成，与 u 无关，估计一致；且恰识别时与 IV 公式代数等价。第一阶段 F 统计量小于 10 常被视为弱工具警戒线：此时 IV 偏误向 OLS 靠拢、且标准误失真。

§23.3IV 估的是什么

处理效应异质时，IV 识别的是局部平均处理效应 LATE：被工具「推动」而改变行为的那一群人（compliers）的平均效应，而不是全体 ATE。条件包括无关性、单调性（无 defiers）与排他性。

排他性不能由数据检验（只能在不恰好识别时做过识别检验，且检验力有限）。它必须靠制度背景、研究设计与因果图来论证。把「找到显著的第一阶段」当成 IV 有效，是最常见的误用。

§Python 建模实例

内生性偏误、IV/2SLS 等价与弱工具变量

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 23-iv.py | 工具变量与两阶段最小二乘（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
N, REPS = 20000, 400
BETA1 = 2.0
PI_STRONG, PI_WEAK = 0.8, 0.05
S_U, S_E = 1.0, 1.0

def cov(a, b):
    ma, mb = statistics.fmean(a), statistics.fmean(b)
    return sum((a[i] - ma) * (b[i] - mb) for i in range(len(a))) / len(a)

def slope(xs, ys):
    return cov(xs, ys) / cov(xs, xs)

def dgp(rng, n, pi):
    z = [rng.gauss(0, 1) for _ in range(n)]
    u = [rng.gauss(0, S_U) for _ in range(n)]
    e = [rng.gauss(0, S_E) for _ in range(n)]
    x = [pi * z[i] + 0.6 * u[i] + e[i] for i in range(n)]
    y = [1.0 + BETA1 * x[i] + u[i] for i in range(n)]
    return z, x, y

def estimate(z, x, y):
    b_ols = slope(x, y)
    b_iv = cov(z, y) / cov(z, x)
    pi1 = slope(z, x)
    zbar, xbar = statistics.fmean(z), statistics.fmean(x)
    xhat = [xbar + pi1 * (zi - zbar) for zi in z]
    b_2sls = slope(xhat, y)
    return b_ols, b_iv, b_2sls, pi1

rng = random.Random(7)
z, x, y = dgp(rng, N, PI_STRONG)
b_ols, b_iv, b_2sls, pi1 = estimate(z, x, y)
# ---- 弱工具：重复抽样的 IV 分布 ----
weak_rng = random.Random(19)
weak_iv = []
for _ in range(REPS):
    zz, xx, yy = dgp(weak_rng, 500, PI_WEAK)
    weak_iv.append(cov(zz, yy) / cov(zz, xx))
# ---- 数值验证：打印可手算核对的量 ----
print("真实 beta1=%.2f" % BETA1)
print("OLS=%.6f (内生性导致上偏)  IV=%.6f  2SLS=%.6f" % (b_ols, b_iv, b_2sls))
print("IV 与 2SLS 差=%.2e (代数等价)" % abs(b_iv - b_2sls))
print("第一阶段斜率 pi1=%.6f (强工具)" % pi1)
print("弱工具 %d 次: IV 均值=%.4f 标准差=%.4f (偏回 OLS 且方差巨大)" %
      (REPS, statistics.fmean(weak_iv), statistics.pstdev(weak_iv)))

操作：把 PI_STRONG 改成 0.05，观察 IV 是否向 OLS 靠拢；把 0.6*u 改成 0（无内生性）看 OLS 是否回到 2。　预期与判读：OLS≈2.29 明显上偏；IV 与 2SLS 都≈1.99 且差在 1e−16 量级；强工具第一阶段斜率≈0.80；弱工具重复抽样下 IV 均值≈2.28 偏向 OLS、标准差≈9.3，方差爆炸。

改参数看趋势：0.6 这个系数控制内生性强度；PI 越小工具越弱；N 越大 IV 越接近真值。　文件位置：part4/23-iv/code/23-iv.py

§常见误区

  • 以为样本量能解决内生性：偏误不随 N 消失。
  • 只报告第一阶段显著就宣称 IV 有效：排他性需制度性论证。
  • 忽略弱工具：会使估计偏向 OLS 并让 t 检验失真。
