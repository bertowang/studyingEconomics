给程序员的翻译

OLS 是把 y 正交投影到 X 的列空间：β̂ = (XᵀX)⁻¹Xᵀy 就是正规方程的解；标准误来自残差方差乘以 (XᵀX)⁻¹ 的对角元——数据越「各方向都有变化」，矩阵越良态，估计越稳。

  • 说明 OLS 无偏所需的假设，并用蒙特卡洛验证抽样分布
  • 解释 R² 与因果解释力无关、共线性如何放大标准误

§21.1投影与正规方程

最小化 SSR(β)=Σ(y_i−x_i'β)²，令梯度为零得正规方程 X'X·β̂ = X'y：

β̂ = (XᵀX)⁻¹Xᵀy ; 残差 e = y − Xβ̂ 满足 Xᵀe = 0（正交性）

若 E[u|X]=0（外生性），则 E[β̂|X]=β；在同方差且无自相关时 Var(β̂|X)=σ²(XᵀX)⁻¹，高斯-马尔可夫定理说它是线性无偏估计量中方差最小的（BLUE）。注意无偏性不依赖正态假设，正态只用于小样本精确推断。

§21.2标准误、t 值与 R²

用 s² = e'e/(n−k) 估计 σ²，标准误 se(β̂_j)=√(s²·[(XᵀX)⁻¹]_{jj})，t=(β̂_j−β_{j,0})/se 在 H₀ 下近似 t(n−k)。R² 衡量样本内拟合：

R² = 1 − RSS/TSS ; 加变量永远不会降低 R²（调整 R² 才惩罚自由度）

R² 高不代表模型可用于因果解释：第 25 章 · 时间序列：平稳性、单位根与伪回归 的伪回归能给出很高的 R²；反过来 第 20 章 · 识别：从数据生成过程到因果参数 里随机实验的 R² 可能很低但 ATE 估计完全可信。判断因果靠识别假设，不靠拟合优度。

§Python 建模实例

手写矩阵求逆、OLS 全量输出与蒙特卡洛

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 21-ols.py | 从零实现多元 OLS：beta / se / t / R2（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
N, REPS = 400, 500
BETA = [1.0, 2.0, -1.5]       # 截距, x1, x2 的真实系数
NOISE_SD = 1.0

def inverse(a):
    n = len(a)
    m = [list(a[i]) + [1.0 if i == j else 0.0 for j in range(n)]
          for i in range(n)]
    for col in range(n):
        piv = max(range(col, n), key=lambda r: abs(m[r][col]))
        m[col], m[piv] = m[piv], m[col]
        p = m[col][col]
        for j in range(2 * n):
            m[col][j] /= p
        for r in range(n):
            if r != col:
                f = m[r][col]
                if f:
                    for j in range(2 * n):
                        m[r][j] -= f * m[col][j]
    return [row[n:] for row in m]

def ols(rows, ys):
    xtx = [[0.0] * 3 for _ in range(3)]
    xty = [0.0] * 3
    for row, y in zip(rows, ys):
        for i in range(3):
            xty[i] += row[i] * y
            for j in range(3):
                xtx[i][j] += row[i] * row[j]
    inv = inverse(xtx)
    beta = [sum(inv[i][j] * xty[j] for j in range(3)) for i in range(3)]
    resid = [y - sum(b * x for b, x in zip(beta, row))
             for row, y in zip(rows, ys)]
    k = 3
    s2 = sum(r * r for r in resid) / (len(ys) - k)
    se = [math.sqrt(s2 * inv[i][i]) for i in range(3)]
    my = statistics.fmean(ys)
    tss = sum((y - my) ** 2 for y in ys)
    rss = sum(r * r for r in resid)
    return beta, se, 1 - rss / tss

def sample(seed_rng):
    rows, ys = [], []
    for _ in range(N):
        x1 = seed_rng.uniform(0, 10)
        x2 = 0.5 * x1 + seed_rng.gauss(0, 1)
        u = seed_rng.gauss(0, NOISE_SD)
        rows.append([1.0, x1, x2])
        ys.append(BETA[0] + BETA[1] * x1 + BETA[2] * x2 + u)
    return rows, ys

rng = random.Random(7)
rows, ys = sample(rng)
beta, se, r2 = ols(rows, ys)
# ---- 蒙特卡洛：验证无偏与标准误 ----
mc_rng = random.Random(11)
b1s, t1s = [], []
for _ in range(REPS):
    rr, yy = sample(mc_rng)
    b, s, _ = ols(rr, yy)
    b1s.append(b[1])
    t1s.append((b[1] - BETA[1]) / s[1])
# ---- 数值验证：打印可手算核对的量 ----
print("真实 beta =", BETA)
print("估计 beta = [%.6f, %.6f, %.6f]" % tuple(beta))
print("标准误   = [%.6f, %.6f, %.6f]" % tuple(se))
print("t 值(H0:beta=0) = [%.3f, %.3f, %.3f]" %
      tuple(beta[i] / se[i] for i in range(3)))
print("R²=%.4f  残差均值=%.6f (应近 0)" %
      (r2, statistics.fmean([y - sum(b * x for b, x in zip(beta, row))
                            for row, y in zip(rows, ys)])))
print("蒙特卡洛 %d 次: beta1 均值=%.6f 标准差=%.6f 单次 se=%.6f" %
      (REPS, statistics.fmean(b1s), statistics.pstdev(b1s), se[1]))
print("|t|>1.96 比例=%.4f (名义 0.05)" %
      (sum(1 for t in t1s if abs(t) > 1.96) / REPS))

操作：把 NOISE_SD 改成 3，观察标准误与 t 值是否按 σ 放大；把 N 改成 100 看 se 是否约翻倍。　预期与判读：β̂≈(1.14, 2.01, −1.56)，与真值 (1, 2, −1.5) 在标准误范围内一致，残差均值≈0，R²≈0.94；500 次重复中 β̂₁ 均值≈2.000、标准差≈0.029 与单次 se≈0.030 接近，|t|>1.96 的比例≈0.034（有限样本略低于名义 0.05）。

改参数看趋势：NOISE_SD 越大 se 越大；N 越大 se 按 1/√N 缩小；x2 与 x1 相关性越高，se 膨胀越明显。　文件位置：part4/21-ols/code/21-ols.py

§常见误区

  • 把 R² 当作因果可信度：伪回归、遗漏变量都可能给出高 R²。
  • 把无偏性当成「一次估计必然接近真值」：无偏是重复抽样性质，见 第 02 章 · 概率、统计与模拟：从分布到证据。
  • 忽略近共线性：XᵀX 接近奇异时求逆数值不稳、标准误暴涨。
