给程序员的翻译

DGP 是「带已知答案的测试夹具」；识别是检查「从可观测日志里能不能反解出参数」，估计是「样本有限时解得准不准」，推断是「误差有多大」。三者是不同的失败模式。

§20.1潜在结果与 ATE

对每个个体 i 定义两个潜在结果 Y_i(1)（接受处理）与 Y_i(0)（未接受），个体处理效应 τ_i = Y_i(1) − Y_i(0)，目标参数通常是 ATE = E[τ_i]。观测到的只有 Y_i = D_i Y_i(1) + (1−D_i)Y_i(0)：每个个体都缺一半数据，这就是因果推断的根本问题。

§20.2朴素差异的偏误分解

把组间均值差拆开：

E[Y|D=1] − E[Y|D=0] = ATT + { E[Y(0)|D=1] − E[Y(0)|D=0] }

第二项是选择偏误：处理组即使不处理，本来结果也不同。随机化使 D ⟂ (Y(1),Y(0))，第二项归零；观察性研究里则要靠「依可观测变量条件独立」（D ⟂ Y(0) | X）或 第 23 章 · 内生性与工具变量：2SLS 的手写实现、第 24 章 · 面板与准实验：DID、固定效应与断点回归 的设计型识别策略。

顺序不能倒过来：控制更多变量不等于识别更好；若控制的是处理之后的变量（对撞变量 / 中介），反而会引入新偏误。先画因果图（DAG）写清 DGP，再决定回归里放什么，这是程序员最容易凭直觉跳错的一步。

§20.3模拟：把识别假设做成实验

本章脚本构造「能力高者更可能参加培训」的 DGP，真实 ATE 已知为 2。三种估计对比：直接用观测组间差（偏）、随机指派（无偏）、按能力分层后加权（分层越细越接近无偏，本例只分四层会残留少量偏误）。这是全书后续所有计量脚本的模板：已知真值 → 生成数据 → 估计 → 比较。

最后提醒卢卡斯批判：若政策本身改变了行为方程（例如培训补贴改变了谁去培训），历史数据估计出的参数就不能直接用于反事实预测。这与「训练分布与部署分布不一致」是同一个问题。

§Python 建模实例

潜在结果、选择偏误与随机化

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 20-identification.py | 已知真值 ATE 的识别实验（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
N = 20000
TAU = 2.0                 # 真实 ATE
BETA_ABILITY = 0.5        # 能力对基线结果的影响
NOISE_SD = 0.5
# ---- DGP: 能力 A 决定自我选择，Y(1)=Y(0)+TAU ----
ability = [random.gauss(0, 1) for _ in range(N)]
d = [1 if a + random.gauss(0, 1) > 0 else 0 for a in ability]
y0 = [1.0 + BETA_ABILITY * a + random.gauss(0, NOISE_SD) for a in ability]
y1 = [v + TAU for v in y0]
y = [y1[i] if d[i] else y0[i] for i in range(N)]
ate_true = statistics.fmean([y1[i] - y0[i] for i in range(N)])
# ---- 估计 1: 观测组间差 ----
m1 = statistics.fmean([y[i] for i in range(N) if d[i] == 1])
m0 = statistics.fmean([y[i] for i in range(N) if d[i] == 0])
naive = m1 - m0
sel_bias = statistics.fmean([y0[i] for i in range(N) if d[i] == 1]) - \
           statistics.fmean([y0[i] for i in range(N) if d[i] == 0])
# ---- 估计 2: 随机指派（反事实实验）----
d_r = [1 if random.random() < 0.5 else 0 for _ in range(N)]
y_r = [y1[i] if d_r[i] else y0[i] for i in range(N)]
mr1 = statistics.fmean([y_r[i] for i in range(N) if d_r[i] == 1])
mr0 = statistics.fmean([y_r[i] for i in range(N) if d_r[i] == 0])
rand_est = mr1 - mr0
# ---- 估计 3: 按能力分层后加权（条件独立）----
order = sorted(range(N), key=lambda i: ability[i])
strata = [order[k * N // 4:(k + 1) * N // 4] for k in range(4)]
strat_est = 0.0
for s in strata:
    t = [i for i in s if d[i] == 1]
    c = [i for i in s if d[i] == 0]
    strat_est += (statistics.fmean([y[i] for i in t]) -
                  statistics.fmean([y[i] for i in c])) * len(s) / N
# ---- 数值验证：打印可手算核对的量 ----
print("真实 ATE=%.4f 处理组比例=%.4f" % (ate_true, sum(d) / N))
print("朴素组间差=%.4f = ATE %.4f + 选择偏误 %.4f" % (naive, ate_true, sel_bias))
print("随机指派估计=%.4f (误差 %.4f)" % (rand_est, rand_est - ate_true))
print("按能力四分层估计=%.4f (误差 %.4f)" % (strat_est, strat_est - ate_true))

操作：把 BETA_ABILITY 改成 0（能力不影响结果），观察选择偏误是否消失。　预期与判读：真实 ATE=2；朴素组间差≈2.55 = 2 + 选择偏误≈0.55；随机指派≈2.00；按能力四分层≈2.08（分层过粗残留约 0.08 偏误，把分层数加到 20 会明显减小）。

改参数看趋势：BETA_ABILITY 越大选择偏误越大；NOISE_SD 越大估计方差越大；N 越大随机误差越小。　文件位置：part4/20-identification/code/20-identification.py

§常见误区

  • 把「控制了更多变量」当成识别改善：控制对撞变量或中介会引入偏误。
  • 把相关系数的显著性当成因果证据：显著性只回答抽样误差，不回答识别。
  • 忽略外部效度：样本上的 ATE 未必能外推到另一个人群或政策规模。

§习题与思考

  1. 在脚本里加入一个「处理后变量」作为控制，观察估计为何变坏。
  2. 把处理效应改成异质 τ_i = 2 + A_i，分别计算 ATE 与 ATT 并比较。
  3. 用 第 02 章 · 概率、统计与模拟：从分布到证据 的语言说明：为什么随机指派相当于消除了 D 与 u 的相关。
