给程序员的翻译

普通 se 假设每个样本的噪声水平相同；稳健 se 允许每个观测有自己的噪声尺度，相当于给每个残差单独加权再重估协方差矩阵，是「不对误差分布做强假设」的防御式实现。

学习目标

  • 通过重复抽样比较普通 se 与稳健 se 的假阳性率
  • 用 DW 统计量与 VIF 诊断自相关和共线性

§22.1异方差：点估计无偏，推断失真

若 Var(u_i|X)=σ_i² 非常数，β̂ 仍无偏（只要 E[u|X]=0），但 Var(β̂) 不再是 σ²(XᵀX)⁻¹。一致估计量（以一元回归为例）：

Var_HC0(β̂₁) = Σ e_i²(x_i−x̄)² / [Σ(x_i−x̄)²]² (White / Eicker–Huber–White)

矩阵形式是三明治 (XᵀX)⁻¹ (Σ e_i² x_i x_iᵀ) (XᵀX)⁻¹。小样本下 HC0 偏乐观，实际常用 HC1/HC3 做自由度修正。若已知异方差结构，FGLS/WLS 可以提高效率，但错误设定权重反而更糟。

§22.2自相关与共线性的诊断量

时间序列残差若满足 AR(1) e_t=ρe_{t−1}+v_t，Durbin–Watson 统计量近似 DW≈2(1−ρ)：接近 2 表示无自相关，接近 0 表示强正相关。多重共线性用方差膨胀因子度量：

VIF_j = 1/(1−R_j²) ; se 膨胀倍数 = √VIF_j

共线性不是「模型错了」，而是数据里缺少识别该系数所需的变化：r=0.99 时 se 膨胀约 7 倍。解法是增加信息（更多样本、实验设计）或正则化/降维，而不是删掉「不显著」的变量了事。

§22.3诊断不是猎巫

症状可能原因先做什么
残差漏斗形异方差 / 函数形式错画残差-拟合图；改用稳健 se
DW 明显小于 2遗漏时间趋势 / 序列相关加趋势或滞后，见 第 25 章 · 时间序列：平稳性、单位根与伪回归
系数符号反常且不显著共线性 / 度量误差看相关矩阵与 VIF

重要边界：诊断检验本身也有多重检验问题（第 31 章 · 复现、多重检验与研究规范），在报告结果前反复试 specification 会抬高假阳性率。预注册分析计划、报告全部设定，是更可靠的做法。

§Python 建模实例

异方差稳健标准误、DW 与 VIF

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 22-diagnostics.py | 手写 HC0 与诊断量（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
N, REPS = 200, 1000
B0, B1 = 1.0, 2.0
RHO_AR = 0.7

def ols1(xs, ys):
    mx, my = statistics.fmean(xs), statistics.fmean(ys)
    dx = [x - mx for x in xs]
    sxx = sum(v * v for v in dx)
    sxy = sum(dx[i] * (ys[i] - my) for i in range(len(xs)))
    b = sxy / sxx
    a = my - b * mx
    e = [ys[i] - a - b * xs[i] for i in range(len(xs))]
    s2 = sum(v * v for v in e) / (len(xs) - 2)
    se = math.sqrt(s2 / sxx)
    se_rob = math.sqrt(sum(e[i] ** 2 * dx[i] ** 2 for i in range(len(xs))) / sxx ** 2)
    return a, b, se, se_rob, e

def one_sample(rng):
    xs = [10.0 * i / N for i in range(N)]
    # 异方差: 噪声标准差随 x 增大
    ys = [B0 + B1 * x + rng.gauss(0, 0.5 + 0.3 * x) for x in xs]
    return xs, ys

rng = random.Random(7)
xs, ys = one_sample(rng)
a, b, se, se_rob, e = ols1(xs, ys)
# ---- 蒙特卡洛：两种 se 的假阳性率 ----
mc = random.Random(23)
r_ordinary, r_robust = 0, 0
for _ in range(REPS):
    xx, yy = one_sample(mc)
    _, bb, s1, s2, _ = ols1(xx, yy)
    if abs((bb - B1) / s1) > 1.96:
        r_ordinary += 1
    if abs((bb - B1) / s2) > 1.96:
        r_robust += 1
# ---- AR(1) 残差与 DW ----
ar_rng = random.Random(31)
prev, errs = 0.0, []
for _ in range(N):
    prev = RHO_AR * prev + ar_rng.gauss(0, 1)
    errs.append(prev)
dw = sum((errs[i] - errs[i - 1]) ** 2 for i in range(1, N)) / sum(v * v for v in errs)
# ---- 共线性：VIF 与 se 膨胀 ----
vifs = [(r, 1 / (1 - r * r), math.sqrt(1 / (1 - r * r))) for r in (0.0, 0.9, 0.99)]
# ---- 数值验证：打印可手算核对的量 ----
print("单样本 beta1=%.6f (真实 %.2f) 普通 se=%.6f 稳健 se=%.6f" % (b, B1, se, se_rob))
print("蒙特卡洛 %d 次 H0 假阳性率: 普通 se=%.4f 稳健 se=%.4f (名义 0.05)" %
      (REPS, r_ordinary / REPS, r_robust / REPS))
print("DW=%.4f ≈ 2(1-rho)=%.4f" % (dw, 2 * (1 - RHO_AR)))
for r, vif, infl in vifs:
    print("  相关系数 r=%.2f  VIF=%.2f  se 膨胀=%.2f 倍" % (r, vif, infl))

操作：把 DGP 里的 0.3*x 改成 0（同方差），观察普通 se 与稳健 se 是否接近、假阳性率是否都回到 0.05。　预期与判读：β̂₁≈2.02，普通 se≈0.056、稳健 se≈0.062；1000 次重复中普通 se 的假阳性率≈0.074，HC0 稳健 se≈0.063（明显改善但小样本仍偏高）；DW≈0.72，与 2(1−ρ)=0.6 同一量级；r=0.99 时 se 膨胀约 7.09 倍。

改参数看趋势：RHO_AR 越接近 1，DW 越接近 0；N 变小会放大 HC0 的小样本偏差。　文件位置：part4/22-diagnostics/code/22-diagnostics.py

§常见误区

  • 以为异方差使 β̂ 有偏：它破坏的是推断效率与标准误，不是无偏性。
  • 把稳健标准误当成万能药：存在内生性或聚类相关时仍不够。
  • 靠反复删变量解决共线性：这会引入设定搜索偏误，见 第 31 章 · 复现、多重检验与研究规范。
