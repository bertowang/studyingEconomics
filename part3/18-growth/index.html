§18.1索洛模型：一个一维动力系统

人均生产函数 y = A·k^α（0<α<1，来自 第 06 章 · 生产者理论、成本曲线与供给 的规模报酬不变技术），资本积累：

k_{t+1} = (1−δ)k_t + s·A·k_t^α ; 稳态 s·A·k*^α = δ·k*

k* = (sA/δ)^{1/(1−α)} , y* = (sA/δ)^{α/(1−α)}

因为 α<1，k^α 的增长慢于 k，投资终将被折旧追上。储蓄率 s 提高只能把经济抬到更高的稳态水平，不能维持长期增长率；人均长期增长必须靠 A 的持续提高（外生的技术进步）。

§18.2条件收敛与黄金律

离自身稳态越远，增长速度越快，这解释了条件收敛：在储蓄率、人口增长、制度与技术相近的国家之间，穷国增长更快；无条件对比所有国家则不成立。跨国实证常用 第 21 章 · 最小二乘：手写 OLS、标准误与高斯-马尔可夫 的回归检验「初始人均 GDP 的系数显著为负，且控制住 s、n、人力资本」。

稳态消费 c* = (1−s)f(k*) 关于 s 先升后降。令 dc*/ds=0 得黄金律 f'(k_gr)=δ，Cobb-Douglas 下 s_gr=α：把过多产出用于积累反而降低长期消费（动态无效率）。

§18.3内生增长：把 A 变成变量

AK 模型令 y = A·k（资本边际报酬不递减，把人力资本、知识溢出都算进广义资本）：

Δk/k = sA − δ = g ⇒ 增长率由 s 与 A 永久决定，无稳态

两模型给出完全不同的可检验含义：索洛预测储蓄率变化只带来水平效应、且存在条件收敛；AK 预测增长效应持续、贫富差距不自动缩小。研发驱动的增长模型（Romer）、创造性破坏（Aghion–Howitt）与人力资本模型则进一步解释 A 从何而来，把 第 10 章 · 市场势力：垄断定价、勒纳指数与价格歧视 的垄断租金与 第 12 章 · 外部性、公共品与科斯谈判 的知识外部性接进增长框架。

§Python 建模实例

索洛稳态、收敛速度与黄金律

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 18-solow.py | 资本积累动力系统与条件收敛（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
A_PROD, ALPHA, DELTA = 1.0, 0.4, 0.05
SAVE = 0.2
K_POOR, K_RICH = 1.0, 8.0
PERIODS = 120
# ---- 模型 ----
def f(k):
    return A_PROD * (k ** ALPHA)

def step(k, s=SAVE):
    return (1 - DELTA) * k + s * f(k)

def steady(s):
    return (s * A_PROD / DELTA) ** (1 / (1 - ALPHA))

k_star = steady(SAVE)
k_gr = (ALPHA * A_PROD / DELTA) ** (1 / (1 - ALPHA))
s_gr = DELTA * (k_gr ** (1 - ALPHA)) / A_PROD
c_star = (1 - SAVE) * f(k_star)
c_gr = (1 - s_gr) * f(k_gr)
# ---- 条件收敛：穷国与富国从各自初始点出发 ----
kp, kr = K_POOR, K_RICH
for _ in range(PERIODS):
    kp, kr = step(kp), step(kr)
g_poor = (step(K_POOR) / K_POOR - 1)
g_rich = (step(K_RICH) / K_RICH - 1)
# ---- AK 模型 ----
g_ak = SAVE * A_PROD - DELTA
k_ak = 1.0
for _ in range(20):
    k_ak = (1 - DELTA) * k_ak + SAVE * A_PROD * k_ak
# ---- 数值验证：打印可手算核对的量 ----
print("稳态 k*=%.6f y*=%.6f c*=%.6f" % (k_star, f(k_star), c_star))
print("迭代 %d 期后 k=%.6f (应接近稳态)" % (PERIODS, kp))
print("初始增长率: 穷国(k=1)=%.4f 富国(k=8)=%.4f → 条件收敛" % (g_poor, g_rich))
print("黄金律 k_gr=%.4f s_gr=%.4f (=alpha %.2f) c_gr=%.4f" % (k_gr, s_gr, ALPHA, c_gr))
print("本例 s=%.2f < s_gr 时 c_gr=%.4f > c*=%.4f" % (SAVE, c_gr, c_star))
print("AK: 理论增长率=%.4f, 20 期实际平均=%.4f (无稳态)" %
      (g_ak, (k_ak ** (1 / 20) - 1)))

操作：把 SAVE 从 0.1 扫到 0.6，画出稳态消费曲线并验证最大值在 s=α=0.4。　预期与判读：s=0.2 时 k*≈10.079、y*≈2.520、c*≈2.016；穷国(k=1)初始增长率 15%、富国(k=8)约 0.74%；120 期后 k≈9.75（因 α=0.4 收敛较慢）；黄金律 s=0.4、k=32、c≈2.4；AK 模型增长率恒为 0.15。

改参数看趋势：SAVE 上升提高稳态水平但不改变长期增长率；ALPHA 越大收敛越慢；DELTA 上升压低稳态资本。　文件位置：part3/18-growth/code/18-solow.py

§常见误区

  • 把「储蓄率提高」说成「长期增长率提高」：索洛里只有水平效应和过渡期增长。
  • 把条件收敛说成「穷国一定追上富国」：前提是稳态决定因素相近。
  • 忽略人口增长与折旧：稳态条件是 s·f(k) = (n+δ)k，本例为简化设 n=0。
