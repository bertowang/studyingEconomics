§17.1费雪方程：三个利率一个关系

投资者关心的是购买力，因此名义利率要补偿预期通胀：

i ≈ r + πᵉ ; r ≈ i − πᵉ ; 精确式 1+i = (1+r)(1+πᵉ)

r 是 第 08 章 · 跨期选择与不确定下的决策 欧拉方程里决定跨期消费的实际利率，也是 第 29 章 · 债券、久期与期限结构：利率风险的一阶与二阶 债券定价与 第 27 章 · 均值-方差组合：分散化与有效前沿 组合选择的贴现基准。名义利率低不等于货币宽松：若通胀预期更低，实际利率可能很高。这是读历史数据时最容易踩的坑。

长期中货币中性（货币量变化主要影响价格水平），但短期因价格黏性，实际利率变化会影响产出——这正是 第 16 章 · 短期波动：乘数、IS-LM 与 AD-AS AD-AS 的传导通道。

§17.2泰勒规则与泰勒原理

标准泰勒规则：

i* = r* + π + 0.5(π − π*) + 0.5·y_gap

通胀高于目标 1 个百分点，名义利率应上升 1.5 个百分点，于是实际利率上升 0.5 个百分点，需求降温。这个「名义利率对通胀的响应大于 1」称为泰勒原理：若响应小于 1，通胀上升反而压低实际利率，形成自我强化的不稳定闭环。程序员的读法：闭环增益必须落在稳定区间。

§17.3一次供给冲击的动态路径

把 IS 曲线 y_t = ρy_{t−1} − β(i_t − r* − π_t)、菲利普斯曲线 π_t = π_{t−1} + κy_t − γ(π_{t−1} − π*) 与泰勒规则联立，就能迭代出「油价冲击 → 加息 → 负产出缺口 → 通胀回落」的路径。注意滞后：本期利率影响下一期产出，再影响后续通胀，因此政策存在「打得过猛/过晚」的风险。

这类小型模型用于讲清机制，不是预测工具：参数是校准出来的、预期是适应性的、没有微观基础。真实政策分析用 DSGE 或 VAR，见 第 25 章 · 时间序列：平稳性、单位根与伪回归 时间序列；用历史数据拟合后做反事实还要面对 第 20 章 · 识别：从数据生成过程到因果参数 的卢卡斯批判。

§Python 建模实例

费雪方程、泰勒规则与冲击传导模拟

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 17-monetary.py | 政策利率与通胀动态（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
R_STAR, PI_STAR = 2.0, 2.0
COEF_PI, COEF_Y = 0.5, 0.5       # 泰勒规则增益
RHO_IS, BETA_IS = 0.7, 0.4       # IS: 产出持续性与实际利率敏感度
KAPPA_PC, GAMMA_PC = 0.25, 0.15  # 菲利普斯曲线与预期锚定
PI_SHOCK = 5.0                   # 初始通胀（供给冲击后）
PERIODS = 10
# ---- 费雪方程与泰勒规则表 ----
def taylor(pi, y):
    return R_STAR + pi + COEF_PI * (pi - PI_STAR) + COEF_Y * y

grid = [(2.0, 0.0), (4.0, 0.0), (4.0, -2.0), (1.0, 1.0)]
# ---- 动态模拟 ----
pi, y = PI_SHOCK, 0.0
path = []
for t in range(1, PERIODS + 1):
    i = taylor(pi, y)
    y = RHO_IS * y - BETA_IS * (i - R_STAR - pi)
    pi = pi + KAPPA_PC * y - GAMMA_PC * (pi - PI_STAR)
    path.append((t, i, pi, y, i - pi))
# ---- 数值验证：打印可手算核对的量 ----
print("费雪: i=5%%, pi^e=2%% => 实际利率 r≈%.2f%%" % (5.0 - 2.0))
for p, g in grid:
    print("泰勒规则 pi=%.1f y=%.1f => i*=%.4f 实际利率=%.4f" %
          (p, g, taylor(p, g), taylor(p, g) - p))
print("通胀每高 1pp，名义利率升 %.2fpp，实际利率升 %.2fpp (泰勒原理)" %
      (1 + COEF_PI, COEF_PI))
for t, i, p, g, r in path[:6]:
    print("  t=%d i=%.3f pi=%.3f y_gap=%.3f r_real=%.3f" % (t, i, p, g, r))
print("第 %d 期通胀=%.4f (目标 %.2f)" % (PERIODS, path[-1][2], PI_STAR))

操作：把 COEF_PI 改成 0（违反泰勒原理），观察通胀路径是否不再回落。　预期与判读：费雪 i=5%、πᵉ=2% ⇒ r≈3%；π=4、缺口 0 时 i*=7、实际利率 3；通胀每高 1pp 名义升 1.5pp、实际升 0.5pp；供给冲击后通胀从 5 逐步向 2 回落并伴随负产出缺口。

改参数看趋势：COEF_PI<0 或过小会破坏稳定性；BETA_IS 越大加息对产出的压制越强；GAMMA_PC 越大通胀预期锚定越强。　文件位置：part3/17-monetary-policy/code/17-monetary.py

§常见误区

  • 用名义利率判断松紧：必须减去预期通胀得到实际利率。
  • 把央行反应函数当结构不变：政策规则本身会变，历史拟合不能直接做反事实。
  • 忽略传导滞后：本期加息主要影响后续若干期的产出与通胀。
