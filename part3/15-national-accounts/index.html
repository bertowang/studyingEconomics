给程序员的翻译

三套核算方法是对同一份交易日志的三种 group-by：按买方、按收款方、按增加值分组，总和必须相等；名义与实际的区别是「按当期价格还是按固定基准价格聚合」。

§15.1三套恒等式

GDP 是一国境内一定时期生产的最终产品市场价值。三种算法从不同角度切入：

支出法: Y = C + I + G + NX

收入法: Y = 工资 + 利息 + 租金 + 利润 + 折旧 + 间接税净额

生产法: Y = Σ 各部门增加值 = Σ(产值 − 中间投入)

三者理论上恒等，因为每一笔支出都是另一方的收入；实际统计里出现的差额叫统计误差。由此可推出储蓄-投资恒等式：

S = Y − C − G = I + NX ⇒ NX = S − I (第 19 章 · 开放经济：国际收支、汇率与三元悖论 开放经济的起点)

恒等式不是行为方程：它永远成立，而「S 随利率上升」是需要另加假设的行为关系。混淆两者会让后面的模型推导全盘错位。

§15.2名义、实际与价格指数

名义 GDP 用当期价格，实际 GDP 用基期价格。两者之比是 GDP 平减指数（帕氏形式）：

平减指数 = Σp_t q_t / Σp_0 q_t ; 实际增长率 ≈ 名义增长率 − 通胀率

CPI 用固定基期篮子（拉氏形式）：CPI = Σp_t q_0 / Σp_0 q_0。篮子固定意味着消费者不会用变便宜的商品替代变贵的商品，因此 CPI 系统性高估生活成本涨幅（替代偏差）；此外还有新品引入偏差与质量变化偏差。

费雪理想指数取拉氏与帕氏的几何平均；链式加权则逐年更换基期再连乘，避免长期比较时基期过旧。这是各国统计机构的标准做法。

§Python 建模实例

三种核算口径与四种价格指数

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 15-accounts.py | 国民账户与价格指数（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
P0, Q0 = (1.0, 2.0), (100.0, 50.0)      # 基期价格与数量（两种商品）
P1, Q1 = (1.2, 2.1), (130.0, 60.0)      # 当期
C_SPEND, I_SPEND, G_SPEND = 156.0, 60.0, 40.0
WAGE, PROFIT, DEPREC, TAX = 180.0, 60.0, 20.0, 22.0
# ---- 支出法 / 收入法 ----
nominal0 = sum(p * q for p, q in zip(P0, Q0))
nominal1 = sum(p * q for p, q in zip(P1, Q1))
real1 = sum(p * q for p, q in zip(P0, Q1))
nx = nominal1 - C_SPEND - I_SPEND - G_SPEND
income = WAGE + PROFIT + DEPREC + TAX
value_added = sum(p * q for p, q in zip(P1, Q1)) - 0.0   # 无中间投入
# ---- 价格指数 ----
deflator = nominal1 / real1
laspeyres = sum(p * q for p, q in zip(P1, Q0)) / nominal0
paasche = nominal1 / real1
fisher = math.sqrt(laspeyres * paasche)
real_growth = real1 / nominal0 - 1
nominal_growth = nominal1 / nominal0 - 1
# ---- 数值验证：打印可手算核对的量 ----
print("基期名义 GDP=%.2f 当期名义 GDP=%.2f" % (nominal0, nominal1))
print("支出法 C+I+G+NX=%.2f+%.2f+%.2f+%.2f=%.2f" %
      (C_SPEND, I_SPEND, G_SPEND, nx, C_SPEND + I_SPEND + G_SPEND + nx))
print("收入法 工资+利润+折旧+税=%.2f  生产法增加值=%.2f" % (income, value_added))
print("实际 GDP(基期价)=%.2f 实际增长=%.2f%% 名义增长=%.2f%%" %
      (real1, 100 * real_growth, 100 * nominal_growth))
print("平减指数=%.4f  CPI(拉氏)=%.4f  帕氏=%.4f  费雪=%.4f" %
      (deflator, laspeyres, paasche, fisher))
print("拉氏−帕氏=%.4f (本例为负：数量结构移向涨价更多的商品)" % (laspeyres - paasche))

操作：把 Q1 改成 (100, 50)（产量不变），观察名义增长是否全部来自价格。　预期与判读：基期 200、当期名义 282；三套口径都等于 282；实际 GDP 250、实际增长 25%、名义增长 41%；平减指数 1.128、CPI 1.125、费雪≈1.1265。本例数量结构向涨价更多的商品移动，因此拉氏指数反而略低；若消费者转向相对便宜的商品，才会出现教科书里 CPI 高于平减指数的替代偏差。

改参数看趋势：P1 改变量价拆分；Q1 的结构决定拉氏与帕氏谁更大；加入中间投入可验证生产法恒等式。　文件位置：part3/15-national-accounts/code/15-accounts.py

§常见误区

  • 把恒等式当行为方程：S=I+NX 恒成立，不说明利率如何影响储蓄。
  • 把 CPI 当平减指数：篮子不同、覆盖范围不同（CPI 含进口、不含投资品）。
  • 把名义增长当实际增长：高通胀期两者可以差出一个数量级。
