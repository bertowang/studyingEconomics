给程序员的翻译

乘数是带反馈的迭代：Y ← c·Y + A 收敛到 A/(1−c)，收敛速度由谱半径 c 决定；IS-LM 是两条约束的联立求解，挤出效应来自利率这条额外反馈通道。

§16.1乘数：一个一阶线性反馈

简单凯恩斯模型：消费 C = c₀ + c(Y−T)，计划支出 E = C + I + G + NX，均衡 Y = E：

Y = [c₀ − cT + I + G + NX] / (1−c) ; 支出乘数 = 1/(1−c)

c=0.8 时乘数为 5。数值上它就是迭代 Y_{t+1}=cY_t+A 的不动点，收敛速度由 |c| 决定。储蓄悖论：每家想多存钱（c 下降）使总需求与总收入下降，最终总储蓄未必增加——第 14 章 · 一般均衡与加总：微观部分的收口 合成谬误的最经典案例。

政府税收乘数是 −c/(1−c)，平衡预算乘数为 1（政府支出与税收等额增加时）。这些结论都依赖「有闲置产能、价格不立刻调整」的短期假设。

§16.2IS-LM：加入利率与货币市场

让投资对利率敏感 I = I₀ − d·r，货币需求 L = kY − h·r = M/P。两式联立：

IS: Y(1−c) = A − d·r ; LM: r = (kY − M/P)/h

Y* = [A + d(M/P)/h] / [(1−c) + dk/h]

分母多出 dk/h，使政府支出乘数从 1/(1−c) 降到 1/[(1−c)+dk/h]：财政扩张推高利率，私人投资被挤出。流动性陷阱（h 很大）或投资利率不敏感（d 很小）时挤出很弱，乘数接近简单模型。

§16.3AD-AS 与菲利普斯曲线

框架价格假设主要结论
凯恩斯交叉 / IS-LM价格水平固定产出由总需求决定
AD-AS 短期价格/工资黏性需求冲击同时影响产出与价格
AD-AS 长期价格完全灵活产出回到潜在水平，需求只影响价格

短期总供给曲线向上倾斜，对应菲利普斯曲线 π = πᵉ + κ·产出缺口 + 供给冲击：需求过热推高通胀；但 πᵉ 会随经验调整，因此不存在可长期利用的「通胀换就业」稳定替代关系。第 17 章 · 货币政策、通胀与利率：费雪方程与泰勒规则 的泰勒规则正是把这条关系写进政策反应函数。

§Python 建模实例

乘数迭代、IS-LM 联立与挤出效应

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 16-multiplier.py | 凯恩斯乘数与 IS-LM（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
C_MPC, AUTONOMOUS = 0.8, 100.0
D_INV, K_MONEY, H_MONEY = 20.0, 0.5, 20.0
M_OVER_P = 200.0
DG = 10.0
ITERS = 40
# ---- 简单乘数：迭代求不动点 ----
y = 0.0
for _ in range(ITERS):
    y = C_MPC * y + AUTONOMOUS
y_simple = AUTONOMOUS / (1 - C_MPC)
tax_mult = -C_MPC / (1 - C_MPC)
# ---- IS-LM 联立 ----
def solve_y(a):
    return (a + D_INV * (M_OVER_P / H_MONEY)) / ((1 - C_MPC) + D_INV * K_MONEY / H_MONEY)

def solve_r(y):
    return (K_MONEY * y - M_OVER_P) / H_MONEY
y0, r0 = solve_y(AUTONOMOUS), None
r0 = solve_r(y0)
y1 = solve_y(AUTONOMOUS + DG)
r1 = solve_r(y1)
mult_islm = (y1 - y0) / DG
# ---- 数值验证：打印可手算核对的量 ----
print("迭代 Y=%.4f 解析 Y=%.4f 乘数=%.4f 税收乘数=%.4f" %
      (y, y_simple, 1 / (1 - C_MPC), tax_mult))
print("IS-LM 初始 Y=%.4f r=%.4f" % (y0, r0))
print("G 增加 %.2f 后 Y=%.4f r=%.4f" % (DG, y1, r1))
print("IS-LM 支出乘数=%.4f (简单乘数 %.4f，挤出 %.4f)" %
      (mult_islm, 1 / (1 - C_MPC), 1 / (1 - C_MPC) - mult_islm))
print("储蓄悖论: c 从 0.8 降到 0.6 时均衡 Y 由 %.2f 降到 %.2f" %
      (AUTONOMOUS / (1 - 0.8), AUTONOMOUS / (1 - 0.6)))

操作：把 D_INV 改成 0（投资对利率不敏感），观察 IS-LM 乘数是否回到 5。　预期与判读：迭代收敛到 Y≈500（解析 500），乘数 5、税收乘数 −4；IS-LM 初始 Y≈428.57、r≈0.71；G 增加 10 后 Y≈442.86、r≈1.07，乘数≈1.43；c 降到 0.6 时 Y 从 500 降到 250。

改参数看趋势：D_INV 或 H_MONEY 上升使挤出减弱；C_MPC 上升提高乘数；M_OVER_P 上升通过 LM 右移提高产出。　文件位置：part3/16-is-lm/code/16-multiplier.py

§常见误区

  • 把恒等式 S=I 当成「储蓄增加会带来投资增加」的因果链：短期由收入调整实现相等。
  • 忽略价格黏性前提：长期价格灵活时需求冲击只影响价格水平。
  • 把菲利普斯曲线当作稳定的政策菜单：预期调整会使替代关系消失。
