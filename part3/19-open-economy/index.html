给程序员的翻译

国际收支是一张复式记账表：每笔跨境交易都有借贷两侧，总和恒为零；汇率与利率是两张表之间的换算率，三元悖论说明三个约束不能同时满足（类似分布式系统里的一致性/可用性/分区容忍取舍）。

§19.1国际收支：一张必须配平的表

国民收入恒等式给出

NX = S − I ; CA ≈ NX + 净要素收入 + 经常转移

CA + KA + ΔR ≡ 0 (经常账户 + 资本与金融账户 + 官方储备变动)

含义：经常账户顺差必然对应资本净流出（或储备增加）。把顺差说成「赚了钱」而不说明对应资产变化，是漏掉半张表。浮动汇率下 ΔR≈0，汇率调整使 CA+KA≈0；固定汇率下央行必须被动买卖外汇，储备随之变动。

§19.2汇率、PPP 与实际汇率

定义 e 为本币/外币（数值上升=本币贬值），P 为本国价格水平、P* 为外国价格水平：

实际汇率 ε = e·P*/P ; PPP 隐含名义汇率 e_PPP = P/P* ; ε=1 时购买力平价成立

ε>1 表示本国商品相对便宜（实际贬值），有利于净出口。PPP 是长期锚而非短期定价公式：可贸易品套利、运输成本、非贸易品（服务、房租）与生产率差异（巴拉萨–萨缪尔森效应）都会造成系统性偏离。

§19.3利率平价与三元悖论

无抛补利率平价（UIP）与抛补利率平价（CIP）：

UIP: i ≈ i* + E[Δe]/e ; CIP: F = S·(1+i)/(1+i*)

若资本自由流动且汇率固定（预期贬值≈0），则必须有 i=i*：本国央行无法独立设定利率。三元悖论说，汇率稳定、资本自由流动、货币政策独立三者只能取二。小国选固定汇率往往要接受他国货币政策；要独立政策则需浮动汇率或资本管制。

接口：CIP 是 第 30 章 · 期权、二叉树与蒙特卡洛：无套利定价的闭环 无套利定价的直接前身——远期价格不是预测，而是由即期价格与两国利率「算」出来的；风险溢价、交易成本与危机时的信用利差会让 CIP 出现偏离。

§Python 建模实例

国际收支、PPP、利率平价与三元悖论

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 19-open.py | 开放经济的核心恒等式（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
C_SPEND, I_SPEND, G_SPEND, Y_OUT = 700.0, 280.0, 300.0, 1300.0
KA_FLOW = -30.0
E_SPOT, P_HOME, P_FOREIGN = 7.0, 8.0, 1.2
I_HOME, I_FOREIGN = 0.05, 0.03
RISK_PREMIUM = 0.01
# ---- 国民账户与国际收支 ----
saving = Y_OUT - C_SPEND - G_SPEND
nx = Y_OUT - C_SPEND - I_SPEND - G_SPEND
ca = nx
reserve_change = -(ca + KA_FLOW)
# ---- 汇率与 PPP ----
real_ex = E_SPOT * P_FOREIGN / P_HOME
e_ppp = P_HOME / P_FOREIGN
misalign = (E_SPOT - e_ppp) / e_ppp
# ---- 利率平价 ----
expected_dep = I_HOME - I_FOREIGN
e_expected = E_SPOT * (1 + expected_dep)
forward = E_SPOT * (1 + I_HOME) / (1 + I_FOREIGN)
fixed_rate_i = I_FOREIGN + RISK_PREMIUM
# ---- 数值验证：打印可手算核对的量 ----
print("S=%.2f  I=%.2f  NX=S-I=%.2f  (支出法 NX=%.2f)" %
      (saving, I_SPEND, saving - I_SPEND, nx))
print("国际收支: CA=%.2f KA=%.2f ΔR=%.2f  合计=%.2f" %
      (ca, KA_FLOW, reserve_change, ca + KA_FLOW + reserve_change))
print("实际汇率 eps=%.4f  PPP 隐含 e=%.4f  名义偏离=%.2f%%" %
      (real_ex, e_ppp, 100 * misalign))
print("UIP 预期贬值=%.4f 预期即期 e=%.4f  CIP 远期 F=%.4f" %
      (expected_dep, e_expected, forward))
print("固定汇率+资本自由流动: 本国 i 必须≈%.4f (含风险溢价)，无法独立设为 %.2f" %
      (fixed_rate_i, I_HOME))

操作：把 E_SPOT 改成 6.0，观察实际汇率与 PPP 偏离的符号；把 I_FOREIGN 改成 0.05 看利差与远期如何变化。　预期与判读：S=300、I=280、NX=20；CA=20、KA=−30、ΔR=10，合计为 0；ε=1.05、PPP 隐含 e≈6.6667，即期汇率比 PPP 隐含值高 5%（本币实际低估）；UIP 预期贬值 2%、预期 e=7.14、CIP 远期≈7.1359；固定汇率下 i≈4%。

改参数看趋势：E_SPOT 上升（本币贬值）抬高 ε；两国利差决定远期升贴水；RISK_PREMIUM 上升使固定汇率下本国利率更高。　文件位置：part3/19-open-economy/code/19-open.py

§常见误区

  • 把 CA 顺差当成「净赚的钱」而不看对应的资本流出与储备变化。
  • 把 PPP 当短期汇率预测：它是长期锚，短期由利率、预期与风险偏好主导。
  • 把远期汇率当市场对未来即期的预测：CIP 下它由利差机械决定。
