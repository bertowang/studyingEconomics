给程序员的翻译

beta 就是资产收益对市场因子的回归斜率；CAPM 声称「alpha 应该为零」，即不存在无法用系统性暴露解释的超额收益。检验 CAPM 本质上是在跑一组回归并检验截距。

  • 用横截面回归检验「平均收益与 beta 线性相关」
  • 理解因子模型、有效市场假说与实证异象的关系

§28.1从组合优化到市场均衡

若所有人都按 第 27 章 · 均值-方差组合：分散化与有效前沿 持有同一切点组合，该组合就是市场组合。均衡条件给出：

E[r_i] − r_f = β_i·(E[r_m] − r_f) , β_i = Cov(r_i, r_m)/Var(r_m)

证券市场线（SML）说：期望超额收益只与 beta 线性相关，特有风险不被定价（因为它可分散）。这与 第 12 章 · 外部性、公共品与科斯谈判 的「只内部化边际社会成本」在结构上很像：只给不可消除的部分定价。

实证形式是时间序列回归 r_i − r_f = α_i + β_i(r_m − r_f) + ε_i；CAPM 预言所有 α_i=0。α_i 显著不为零即 Jensen's alpha，可能来自定价错误，也可能来自模型设定错误（联合检验问题）。

§28.2横截面检验与因子扩展

两步法：先估每只股票的 β̂，再用平均超额收益对 β̂ 做横截面回归，斜率应约等于市场风险溢价。实证中斜率往往偏平、截距偏高，小市值与高账面市值比股票收益系统性偏高，于是有 Fama–French 三因子：

r_i − r_f = α + β_m MKT + β_s SMB + β_h HML + ε

后续又加入动量、盈利、投资等因子，形成「因子动物园」。这里要带着 第 31 章 · 复现、多重检验与研究规范 的警觉：从大量候选因子里挑显著的，本身就是多重检验问题；样本外表现与经济学解释同样重要。

§28.3有效市场与行为金融的张力

命题含义可检验推论
弱式有效价格已含历史价格信息收益不可由自身滞后预测
半强式有效价格已含公开信息事件公告后无持续漂移（实际有 PEAD）
行为金融存在系统性认知偏差动量、反转、处置效应、泡沫

Grossman–Stiglitz 的洞见：若市场完全有效，收集信息就没有回报，于是没人收集信息，价格又不会反映信息。均衡只能是「近似有效」，留出刚好补偿信息成本的价格偏差。

§Python 建模实例

估计 beta/alpha、横截面检验与因子增量 R²

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 28-capm.py | CAPM 时间序列与横截面回归（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
T = 240                      # 20 年月度
RF_M, MU_M_M, SD_M_M = 0.03 / 12, 0.08 / 12, 0.16 / math.sqrt(12)
N_ASSETS = 12
BETAS = [0.4 + 0.12 * i for i in range(N_ASSETS)]
ALPHAS = [0.0] * N_ASSETS
IDIO_SD = 0.01

def mean(v):
    return statistics.fmean(v)

def cov(a, b):
    ma, mb = mean(a), mean(b)
    return sum((a[i] - ma) * (b[i] - mb) for i in range(len(a))) / len(a)

def ols1(xs, ys):
    b = cov(xs, ys) / cov(xs, xs)
    a = mean(ys) - b * mean(xs)
    e = [ys[i] - a - b * xs[i] for i in range(len(xs))]
    tss = sum((y - mean(ys)) ** 2 for y in ys)
    r2 = 1 - sum(v * v for v in e) / tss
    s2 = sum(v * v for v in e) / (len(xs) - 2)
    se = math.sqrt(s2 / (cov(xs, xs) * len(xs)))
    return a, b, se, r2

# ---- DGP: 市场因子 + 三个因子暴露 ----
rng = random.Random(7)
mkt = [rng.gauss(MU_M_M, SD_M_M) for _ in range(T)]
excess_m = [m - RF_M for m in mkt]
smb = [rng.gauss(0.001, 0.02) for _ in range(T)]
hml = [rng.gauss(0.001, 0.02) for _ in range(T)]
series = []
for beta, alpha in zip(BETAS, ALPHAS):
    ri_excess = [alpha + beta * excess_m[t] +
                 0.4 * smb[t] + 0.2 * hml[t] + rng.gauss(0, IDIO_SD)
                 for t in range(T)]
    series.append(ri_excess)
# ---- 第一步：时间序列 CAPM 回归 ----
est = [ols1(excess_m, s) for s in series]
# ---- 第二步：横截面回归 mean(r_i) ~ beta_i ----
xs = [e[1] for e in est]
ys = [mean(s) for s in series]
a_cs, b_cs, se_cs, r2_cs = ols1(xs, ys)
# ---- 三因子回归的 R² 增量 ----
def ols3(rows, y):
    # 用标准库做 4x4 高斯-约当求逆
    n = 4
    xtx = [[0.0] * n for _ in range(n)]
    xty = [0.0] * n
    for row, yi in zip(rows, y):
        for i in range(n):
            xty[i] += row[i] * yi
            for j in range(n):
                xtx[i][j] += row[i] * row[j]
    m = [list(xtx[i]) + [1.0 if i == j else 0.0 for j in range(n)]
         for i in range(n)]
    for c in range(n):
        p = max(range(c, n), key=lambda r: abs(m[r][c]))
        m[c], m[p] = m[p], m[c]
        d = m[c][c]
        for j in range(2 * n):
            m[c][j] /= d
        for r in range(n):
            if r != c:
                f = m[r][c]
                if f:
                    for j in range(2 * n):
                        m[r][j] -= f * m[c][j]
    inv = [row[n:] for row in m]
    b = [sum(inv[i][j] * xty[j] for j in range(n)) for i in range(n)]
    e = [yi - sum(b[k] * row[k] for k in range(n))
         for row, yi in zip(rows, y)]
    tss = sum((yi - mean(y)) ** 2 for yi in y)
    return 1 - sum(v * v for v in e) / tss

rows = [[1.0, excess_m[t], smb[t], hml[t]] for t in range(T)]
r2_3f = ols3(rows, series[0])
# ---- 数值验证：打印可手算核对的量 ----
print("市场月超额收益: 样本=%.6f 理论=%.6f 年化≈%.2f%%" %
      (mean(excess_m), MU_M_M - RF_M, 1200 * mean(excess_m)))
for i in (0, 5, 11):
    a, b, bse, r2 = est[i]
    print("资产%02d beta_hat=%.4f (真 %.2f) beta_se=%.6f alpha_hat=%.6f R2=%.4f" %
          (i + 1, b, BETAS[i], bse, a, r2))
print("横截面斜率=%.6f (对照市场已实现超额收益 %.6f) 截距=%.6f R2=%.4f" %
      (b_cs, mean(excess_m), a_cs, r2_cs))
print("加入 SMB/HML 后资产1 R2: %.4f -> %.4f" % (est[0][3], r2_3f))

操作：把 IDIO_SD 改成 0.03，观察 beta 的 se 与 R² 如何变化；把 T 改成 60 看横截面斜率的噪声。　预期与判读：12 个资产的 β̂ 都接近各自真值（0.4～1.72），α̂ 在 0 附近；横截面斜率接近本次样本的市场已实现月超额收益（理论约 0.0042，20 年样本会有抽样波动）；加入 SMB/HML 后资产 1 的 R² 明显上升。

改参数看趋势：IDIO_SD 越大 R² 越低、beta 越不精确；T 越小横截面斜率越不稳定；因子载荷系数决定 R² 增量。　文件位置：part5/28-capm-factors/code/28-capm.py

§常见误区

  • 把 alpha 显著直接解读为「基金经理能力」：它是相对某个因子模型的残差，模型错则 alpha 也错。
  • 用估计出的 β̂ 做横截面回归却忽略测量误差：会产生变量误差偏误（见 第 23 章 · 内生性与工具变量：2SLS 的手写实现）。
  • 把样本内显著的因子当成可交易收益：需考虑多重检验、交易成本与样本外表现。
