给程序员的翻译

§30.1无套利与风险中性

期权是或有权益，到期 payoff 为 max(S_T−K,0)（看涨）或 max(K−S_T,0)（看跌）。若能用标的与无风险借贷构造复制组合，则价格由无套利唯一确定，与投资者风险偏好无关：

p = (e^{rΔt} − d)/(u − d) ; C₀ = e^{−rΔt}[p·C_u + (1−p)·C_d]

这里 p 是风险中性概率，不是真实上涨概率；真实漂移 μ 被无套利条件替换成 r。这是 第 08 章 · 跨期选择与不确定下的决策 期望效用之后最重要的一次视角转换：定价用等价测度，决策用真实测度。

§30.2Black-Scholes 与平价关系

当二叉树步数趋于无穷，得到连续时间闭式解：

d₁=[ln(S/K)+(r+½σ²)T]/(σ√T) , d₂=d₁−σ√T

C = S·N(d₁) − K·e^{−rT}N(d₂) ; P = K·e^{−rT}N(−d₂) − S·N(−d₁)

N(·) 用标准库 math.erf 实现：N(x)=½[1+erf(x/√2)]。看涨看跌平价 C − P = S − K·e^{−rT} 是检验实现是否正确的最快单元测试。

§30.3蒙特卡洛与对冲

高维或路径依赖 payoff 没有闭式解时，用 S_T = S₀exp[(r−½σ²)T + σ√T Z] 抽样、取贴现平均：

Ĉ = e^{−rT}·(1/N)Σ max(S_T^{(n)}−K,0) ; 标准误 ≈ σ_payoff/√N

误差按 1/√N 下降，与 第 02 章 · 概率、统计与模拟：从分布到证据 的中心极限定理完全一致；降低方差可用对偶变量、控制变量与准随机序列。Δ=∂C/∂S 给出复制组合里需要持有的标的份额，动态再平衡就是 delta 对冲；现实中的离散对冲、交易成本与跳跃风险是模型误差的主要来源。

§Python 建模实例

二叉树、Black-Scholes、蒙特卡洛与平价校验

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 30-options.py | 欧式期权三种定价方法（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
S0, K, R, SIGMA, T = 100.0, 100.0, 0.05, 0.20, 1.0
N_STEPS = 200
N_PATHS = 20000

def norm_cdf(x):
    return 0.5 * (1 + math.erf(x / math.sqrt(2)))

# ---- 1. CRR 二叉树回溯 ----
dt = T / N_STEPS
u = math.exp(SIGMA * math.sqrt(dt))
d = 1 / u
p = (math.exp(R * dt) - d) / (u - d)
disc = math.exp(-R * dt)
call = [max(S0 * (u ** j) * (d ** (N_STEPS - j)) - K, 0.0)
        for j in range(N_STEPS + 1)]
put = [max(K - S0 * (u ** j) * (d ** (N_STEPS - j)), 0.0)
       for j in range(N_STEPS + 1)]
for step in range(N_STEPS, 0, -1):
    call = [disc * (p * call[j + 1] + (1 - p) * call[j]) for j in range(step)]
    put = [disc * (p * put[j + 1] + (1 - p) * put[j]) for j in range(step)]
c_tree, p_tree = call[0], put[0]
# ---- 2. Black-Scholes 闭式解 ----
d1 = (math.log(S0 / K) + (R + 0.5 * SIGMA ** 2) * T) / (SIGMA * math.sqrt(T))
d2 = d1 - SIGMA * math.sqrt(T)
c_bs = S0 * norm_cdf(d1) - K * math.exp(-R * T) * norm_cdf(d2)
p_bs = K * math.exp(-R * T) * norm_cdf(-d2) - S0 * norm_cdf(-d1)
# ---- 3. 蒙特卡洛 ----
rng = random.Random(7)
payoffs = []
for _ in range(N_PATHS):
    z = rng.gauss(0, 1)
    st = S0 * math.exp((R - 0.5 * SIGMA ** 2) * T + SIGMA * math.sqrt(T) * z)
    payoffs.append(max(st - K, 0.0))
c_mc = math.exp(-R * T) * statistics.fmean(payoffs)
mc_se = math.exp(-R * T) * statistics.pstdev(payoffs) / math.sqrt(N_PATHS)
# ---- 4. delta 有限差分 ----
def bs_call(s):
    dd1 = (math.log(s / K) + (R + 0.5 * SIGMA ** 2) * T) / (SIGMA * math.sqrt(T))
    dd2 = dd1 - SIGMA * math.sqrt(T)
    return s * norm_cdf(dd1) - K * math.exp(-R * T) * norm_cdf(dd2)
delta = (bs_call(S0 + 0.01) - bs_call(S0 - 0.01)) / 0.02
# ---- 数值验证：打印可手算核对的量 ----
print("参数: S=K=%.0f r=%.2f sigma=%.2f T=%.0f N=%d" %
      (S0, R, SIGMA, T, N_STEPS))
print("二叉树   call=%.6f put=%.6f" % (c_tree, p_tree))
print("B-S 公式 call=%.6f put=%.6f" % (c_bs, p_bs))
print("蒙特卡洛 call=%.6f ±%.6f (1 倍标准误, %d 路径)" % (c_mc, mc_se, N_PATHS))
print("平价校验 C-P=%.6f  S-K*e^(-rT)=%.6f  差=%.2e" %
      (c_tree - p_tree, S0 - K * math.exp(-R * T),
       abs((c_tree - p_tree) - (S0 - K * math.exp(-R * T)))))
print("delta=%.6f (≈N(d1)=%.6f)" % (delta, norm_cdf(d1)))

操作：把 N_STEPS 改成 10、50、200，观察二叉树价格如何收敛到 B-S；把 N_PATHS 改成 2000 看蒙特卡洛标准误是否按 1/√N 放大。　预期与判读：S=K=100、r=5%、σ=20%、T=1 时二叉树 call≈10.4406/put≈5.5635，B-S call≈10.4506/put≈5.5735（200 步离散误差约 0.01）；蒙特卡洛 call≈10.47 ±0.10；C−P 与 S−K·e^(−rT)≈4.8771 一致；delta≈0.6368。

改参数看趋势：N_STEPS 控制离散化误差；N_PATHS 控制蒙特卡洛误差；SIGMA 上升同时提高 call 与 put 价格。　文件位置：part5/30-options/code/30-options.py

§常见误区

  • 把风险中性概率当真实上涨概率：它只是便于贴现的等价权重。
  • 忽略平价关系校验：它是发现实现 bug 最便宜的手段。
  • 把 BS 的常数波动假设当事实：隐含波动率微笑正是它的系统性偏离。
