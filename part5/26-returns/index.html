§26.1三种收益与两个恒等式

简单收益 R_t = P_t/P_{t−1} − 1，对数收益 r_t = ln(P_t/P_{t−1}) = ln(1+R_t)。多期总收益：

1 + R_total = Π(1+R_t) ; r_total = Σ r_t = ln(1+R_total)

简单收益可跨资产加总（组合收益是加权平均），对数收益可跨时间加总。两者不能混用：把对数收益当权重算组合收益是常见 bug。年化时 μ_ann = 12·μ_month、σ_ann = √12·σ_month（方差可加、标准差不可加）。

§26.2波动拖累

对数效用或连续复利下，长期增长率是几何平均而非算术平均：

g = E[r] − ½σ² （GBM 下精确成立，一般情形下为二阶近似）

因此「平均收益 10%、波动 30%」的资产长期增长率不是 10%，而约 5.5%。第 08 章 · 跨期选择与不确定下的决策 的确定性等价、第 27 章 · 均值-方差组合：分散化与有效前沿 的均值-方差目标函数都在这里得到同一个结论：波动本身要付出复利代价。

§26.3几何布朗运动与路径模拟

标准价格模型 dS = μS dt + σS dW 的离散解：

S_{t+Δt} = S_t·exp[(μ − ½σ²)Δt + σ√Δt·Z] , Z~N(0,1)

S_T 服从对数正态分布，价格水平是 I(1) 而收益近似 I(0)——这正是 第 25 章 · 时间序列：平稳性、单位根与伪回归 的结论。脚本会验证「终点价格 = 初始价 × exp(对数收益之和)」，并用蒙特卡洛均值与解析漂移对照。真实市场还有厚尾、波动聚集与跳跃，GBM 是基准模型而非事实。

§Python 建模实例

复利、波动拖累与 GBM 路径模拟

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 26-returns.py | 收益定义与几何布朗运动（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
S0, MU, SIGMA = 100.0, 0.08, 0.20
DT, STEPS = 1.0 / 12, 240       # 20 年月度
N_PATHS = 4000
# ---- 单条路径 ----
rng = random.Random(7)
prices, logrets, simple = [S0], [], []
s = S0
for _ in range(STEPS):
    z = rng.gauss(0, 1)
    r = (MU - 0.5 * SIGMA ** 2) * DT + SIGMA * math.sqrt(DT) * z
    s *= math.exp(r)
    prices.append(s)
    logrets.append(r)
    simple.append(math.exp(r) - 1)
mean_r = statistics.fmean(logrets)
mean_simple = statistics.fmean(simple)
vol_month = statistics.pstdev(logrets)
total_log = sum(logrets)
# ---- 蒙特卡洛：终点价格期望 E[S_T] = S0*exp(mu*T) ----
mc = random.Random(19)
terminals = []
for _ in range(N_PATHS):
    st = S0 * math.exp((MU - 0.5 * SIGMA ** 2) * (STEPS * DT) +
                       SIGMA * math.sqrt(STEPS * DT) * mc.gauss(0, 1))
    terminals.append(st)
# ---- 最大回撤 ----
peak, mdd = prices[0], 0.0
for p in prices:
    peak = max(peak, p)
    mdd = max(mdd, (peak - p) / peak)
# ---- 数值验证：打印可手算核对的量 ----
print("终点价格=%.4f  S0*exp(sum r)=%.4f (恒等式)" %
      (prices[-1], S0 * math.exp(total_log)))
print("月对数收益均值=%.6f 简单收益均值=%.6f 差≈sigma²*dt/2=%.6f" %
      (mean_r, mean_simple, 0.5 * SIGMA ** 2 * DT))
print("年化对数收益=%.4f%% 年化波动=%.4f%% (目标 %.2f%%)" %
      (100 * mean_r / DT, 100 * vol_month / math.sqrt(DT), 100 * SIGMA))
print("长期增长率 E[r]-0.5sigma²=%.4f%% (算术漂移 %.2f%%)" %
      (100 * (MU - 0.5 * SIGMA ** 2), 100 * MU))
print("蒙特卡洛 E[S_T]=%.4f 解析=%.4f" %
      (statistics.fmean(terminals), S0 * math.exp(MU * STEPS * DT)))
print("单路径最大回撤=%.2f%%" % (100 * mdd))

操作：把 SIGMA 改成 0.4，观察长期增长率下降与最大回撤上升；把 STEPS 改成 12 看年化估计的噪声。　预期与判读：终点价格与 S0·exp(Σr) 完全一致；简单收益均值比对数收益均值高约 σ²Δt/2；年化波动≈20%；长期增长率≈6% 而算术漂移 8%；蒙特卡洛 E[S_T] 接近 S0·e^(μT)。

改参数看趋势：SIGMA 上升同时压低长期增长率、放大回撤；N_PATHS 控制蒙特卡洛误差；DT 改变年化换算系数。　文件位置：part5/26-returns/code/26-returns.py

§常见误区

  • 把对数收益当简单收益做组合加权：跨时间可加与跨资产可加是两种不同性质。
  • 把算术平均当长期增长率：忽略波动拖累会系统性高估终值。
  • 把 GBM 当真实市场：厚尾、波动聚集与跳跃都不在模型里。
