§29.1定价与久期

附息债券价格 P = Σ CF_t/(1+y)^t。由 dP/P = −D_mod·dy + ½C·dy² 定义：

D_mac = Σ t·PV(CF_t)/P ; D_mod = D_mac/(1+y) ; C = Σ t(t+1)PV(CF_t)/[P(1+y)²]

久期也是「现金流的加权平均回收时间」，还是第 01 章 · 约束最优化与比较静态：经济学的核心 API 包络定理意义下的敏感度：D_mod = −(1/P)·∂P/∂y。零息债券的麦考利久期恰好等于期限；票息越高、期限越短，久期越短、利率风险越小。

§29.2即期、远期与期限结构

即期利率 s_t 用于贴现第 t 期现金流；由无套利可推出隐含远期利率：

f(1,2) = (1+s₂)²/(1+s₁) − 1 ; 一般 f(t,t+1) = (1+s_{t+1})^{t+1}/(1+s_t)^t − 1

预期假说认为长期利率是未来短期利率的平均（加期限溢价后为流动性偏好理论）；收益率曲线向上倾斜通常反映预期加息或正的期限溢价，倒挂常被视为衰退信号（实证关联，不是因果定律）。第 17 章 · 货币政策、通胀与利率：费雪方程与泰勒规则 的政策利率通过短端传导到整条曲线。

§29.3利率风险管理的边界

度量回答什么局限
久期收益率平行移动 1bp 的价格变化只适用小幅、平行移动

§Python 建模实例

债券定价、久期/凸性与远期利率

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 29-bonds.py | 现金流贴现与利率敏感度（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
FACE, COUPON_RATE, MATURITY = 100.0, 0.05, 5
YTM = 0.04
SHIFT_BP, SHIFT_BIG = 0.0001, 0.01
S1, S2 = 0.03, 0.04

def price(y):
    cfs = [FACE * COUPON_RATE] * MATURITY
    cfs[-1] += FACE
    return sum(cf / (1 + y) ** t for t, cf in enumerate(cfs, 1))

p0 = price(YTM)
cash = [FACE * COUPON_RATE] * MATURITY
cash[-1] += FACE
pv = [cf / (1 + YTM) ** t for t, cf in enumerate(cash, 1)]
d_mac = sum(t * v for t, v in enumerate(pv, 1)) / p0
d_mod = d_mac / (1 + YTM)
convex = sum(t * (t + 1) * pv[t - 1] for t in range(1, MATURITY + 1)) / \
         (p0 * (1 + YTM) ** 2)
# ---- 泰勒近似 vs 精确重定价 ----
def approx(dy):
    return p0 * (1 - d_mod * dy + 0.5 * convex * dy ** 2)
p_up = price(YTM + SHIFT_BIG)
p_down = price(YTM - SHIFT_BIG)
# ---- 远期利率与期限结构 ----
f12 = (1 + S2) ** 2 / (1 + S1) - 1
# ---- 数值验证：打印可手算核对的量 ----
print("5 年期 5%% 票息、YTM=%.2f%% 价格=%.6f" % (100 * YTM, p0))
print("麦考利久期=%.6f 修正久期=%.6f 凸性=%.6f" % (d_mac, d_mod, convex))
print("+1bp: 久期预测 ΔP=%.6f 精确 ΔP=%.6f" %
      (approx(SHIFT_BP) - p0, price(YTM + SHIFT_BP) - p0))
print("+100bp: 一阶预测=%.6f 二阶预测=%.6f 精确=%.6f" %
      (p0 * (1 - d_mod * SHIFT_BIG), approx(SHIFT_BIG), p_up))
print("利率 +100bp 价格变化=%.4f, -100bp 价格变化=%.4f (不对称来自凸性)" %
      (p_up - p0, p_down - p0))
print("即期 s1=%.2f%% s2=%.2f%% => 隐含远期 f(1,2)=%.4f%%" %
      (100 * S1, 100 * S2, 100 * f12))

操作：把 COUPON_RATE 改成 0（零息债券），验证麦考利久期是否等于 5；把 SHIFT_BIG 改成 0.05 观察二阶近似误差。　预期与判读：5 年期 5% 票息、YTM=4% 时价格≈104.45；麦考利久期≈4.557、修正久期≈4.382、凸性≈24.48；+1bp 时久期预测与精确值几乎一致；+100bp 时一阶预测 99.87、二阶预测 100.003、精确 100.000；零息债券久期=期限。

改参数看趋势：COUPON_RATE 越低久期越长；MATURITY 越长久期与凸性越大；SHIFT_BIG 越大越能看出凸性价值。　文件位置：part5/29-bonds/code/29-bonds.py

§常见误区

  • 把久期当成熟期限：只有零息债券两者才相等。
  • 用久期预测大幅利率变动：需加凸性或直接精确重定价。
  • 把倒挂曲线当确定性衰退信号：它是预期与期限溢价共同作用的结果。
