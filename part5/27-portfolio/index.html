§27.1组合方差：协方差才是关键

两资产权重 w 与 1−w：

μ_p = wμ₁+(1−w)μ₂ ; σ_p² = w²σ₁²+(1−w)²σ₂²+2w(1−w)ρσ₁σ₂

令导数为零得最小方差权重 w* = (σ₂²−ρσ₁σ₂)/(σ₁²+σ₂²−2ρσ₁σ₂)。只要 ρ<1，最小方差组合的风险就低于两种资产各自的风险；ρ=−1 时理论上可构造零方差组合。分散化收益来自协方差项，不是「资产数量多」。

§27.2有效前沿与切点组合

把 (σ_p, μ_p) 对所有权重连成曲线，其上「给定风险收益最高」的半支是有效前沿。加入无风险利率 r_f 后，最大化夏普比率：

Sharpe = (μ_p − r_f)/σ_p ; 最优解 = 从 r_f 出发与前沿相切的切点组合

两基金分离定理：所有投资者的风险资产部分都持有同一个切点组合，差别只在「无风险资产 + 切点组合」的配比，由风险偏好决定。这是 第 08 章 · 跨期选择与不确定下的决策 期望效用与 第 05 章 · 消费者理论：偏好、需求与希克斯分解 对偶结构在金融里的对应：偏好只影响一个标量。

§Python 建模实例

最小方差、有效前沿与最大夏普组合

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 27-portfolio.py | 两资产组合与切点组合（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
MU1, MU2 = 0.08, 0.12
S1, S2, RHO = 0.15, 0.25, 0.30
RF = 0.03
GRID = 1000

def stats(w):
    mu = w * MU1 + (1 - w) * MU2
    var = (w * w * S1 ** 2 + (1 - w) ** 2 * S2 ** 2 +
           2 * w * (1 - w) * RHO * S1 * S2)
    return mu, math.sqrt(var)

w_min = (S2 ** 2 - RHO * S1 * S2) / (S1 ** 2 + S2 ** 2 - 2 * RHO * S1 * S2)
mu_min, sd_min = stats(w_min)
best_w, best_sharpe = 0.0, -1e9
for i in range(GRID + 1):
    w = -0.5 + 1.5 * i / GRID      # 允许少量卖空以看清前沿形状
    mu, sd = stats(w)
    sh = (mu - RF) / sd
    if sh > best_sharpe:
        best_w, best_sharpe = w, sh
mu_t, sd_t = stats(best_w)
# ---- ρ=1 时无分散化收益的对照 ----
cov = RHO * S1 * S2
sd_equal = math.sqrt(0.25 * S1 ** 2 + 0.25 * S2 ** 2 + 0.5 * cov)
sd_equal_rho1 = math.sqrt(0.25 * S1 ** 2 + 0.25 * S2 ** 2 + 0.5 * S1 * S2)
# ---- 数值验证：打印可手算核对的量 ----
print("资产1: mu=%.2f sd=%.2f  资产2: mu=%.2f sd=%.2f  rho=%.2f" %
      (MU1, S1, MU2, S2, RHO))
print("最小方差权重 w*=%.6f 组合 sd=%.6f (低于两资产)" % (w_min, sd_min))
print("最大夏普权重 w=%.6f 夏普=%.6f mu=%.6f sd=%.6f" %
      (best_w, best_sharpe, mu_t, sd_t))
print("等权组合 sd=%.6f ; 若 rho=1 则 sd=%.6f (无分散化收益)" %
      (sd_equal, sd_equal_rho1))
print("切点组合超预期收益/风险 = %.6f = 夏普比率" % ((mu_t - RF) / sd_t))

操作：把 RHO 改成 −0.5 或 1.0，观察最小方差权重与等权组合风险如何变化。　预期与判读：ρ=0.3 时最小方差权重=0.82、组合波动≈0.1431（低于资产 1 的 0.15）；最大夏普权重≈0.5905、夏普≈0.4306；等权组合波动≈0.1639，ρ=1 时为 0.20，无分散化收益。

改参数看趋势：RHO 下降降低组合风险；MU2 上升把切点组合推向资产 2；RF 上升改变切点位置。　文件位置：part5/27-portfolio/code/27-portfolio.py

§常见误区

  • 用资产数量衡量分散化：真正起作用的是相关性与协方差。
  • 把估计出的期望收益当已知参数：μ 的估计误差会主导权重。
  • 把夏普比率当唯一目标：它忽略偏度、厚尾与流动性风险。

  1. 解析推导最大夏普权重并和网格解对比（提示：对 (μ_p−r_f)/σ_p 求导）。
