§31.1p 值不是结论为真的概率

p = P(观测到当前或更极端结果 | H₀ 为真)。它不回答「H₀ 为真的概率」，也不回答「效应有多大」。在 5% 阈值下重复 20 次独立检验，至少一次假阳性的概率是

P(至少一次假阳性) = 1 − (1−0.05)^20 ≈ 0.6415

「花园分叉路径」更隐蔽：不同控制变量、样本窗口、变量变换、剔除规则都算一次尝试，即使研究者没有恶意，最终汇报的那条路径也是被结果选出来的。

§31.2校正、功效与预注册

Bonferroni 把阈值改为 α/m，控制家族错误率（FWER），但保守、降低功效。Benjamini–Hochberg 控制错误发现率（FDR），在高维因子筛选中更常用。另一条路是预注册：先固定假设、主设定、样本与排除规则，再跑数据，把探索性分析与验证性分析明确分开。

还要做功效分析：真实效应 δ、样本量 n、噪声 σ 决定 z ≈ δ√n/σ；低功效研究即使显著，效应量也常被高估（赢家诅咒）。这与 第 21 章 · 最小二乘：手写 OLS、标准误与高斯-马尔可夫 的标准误、第 23 章 · 内生性与工具变量：2SLS 的手写实现 的弱工具在数学上是同一件事：信息量不足时，条件在「显著」上的估计必然偏大。

p-hacking、Bonferroni 与功效分析

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 31-reproducibility.py | 多重检验的蒙特卡洛（只用标准库）
import math, random, statistics
from statistics import NormalDist
random.seed(7)
# ---- 参数区 ----
N, M_TESTS, REPS = 100, 20, 1000
ALPHA = 0.05
TRUE_EFFECT = 0.3

def norm_sf(x):
    return 0.5 * (1 - math.erf(abs(x) / math.sqrt(2)))

def p_from_t(t):
    return 2 * norm_sf(t)

def mean(v):
    return statistics.fmean(v)

def t_stat(xs, ys):
    mx, my = mean(xs), mean(ys)
    sxx = sum((x - mx) ** 2 for x in xs)
    b = sum((xs[i] - mx) * (ys[i] - my) for i in range(len(xs))) / sxx
    e = [ys[i] - my - b * (xs[i] - mx) for i in range(len(xs))]
    s2 = sum(v * v for v in e) / (len(xs) - 2)
    return b / math.sqrt(s2 / sxx)

# ---- t 分布临界值（Cornish-Fisher 一阶修正，df=N-2）----
df = N - 2
def t_crit(alpha):
    z = NormalDist().inv_cdf(1 - alpha / 2)
    return z + (z ** 3 + z) / (4 * df)
crit05 = t_crit(ALPHA)
crit_bonf = t_crit(ALPHA / M_TESTS)
# ---- 原假设为真：20 个候选解释变量都与 y 无关 ----
rng = random.Random(7)
raw, corrected, minp_sum = 0, 0, 0.0
for _ in range(REPS):
    y = [rng.gauss(0, 1) for _ in range(N)]
    ts = []
    for _ in range(M_TESTS):
        x = [rng.gauss(0, 1) for _ in range(N)]
        ts.append(abs(t_stat(x, y)))
    maxt = max(ts)
    minp_sum += p_from_t(maxt)
    if maxt > crit05:
        raw += 1
    if maxt > crit_bonf:
        corrected += 1
# ---- 真实效应下的功效 ----
power_rng = random.Random(19)
hits = 0
for _ in range(REPS):
    x = [power_rng.gauss(0, 1) for _ in range(N)]
    y = [TRUE_EFFECT * x[i] + power_rng.gauss(0, 1) for i in range(N)]
    if abs(t_stat(x, y)) > crit05:
        hits += 1
theory = 1 - (1 - ALPHA) ** M_TESTS
# ---- 数值验证：打印可手算核对的量 ----
print("临界值: t(0.975,df=%d)≈%.4f  Bonferroni 对应≈%.4f" % (df, crit05, crit_bonf))
print("单次检验 alpha=%.2f, m=%d, 独立检验至少一次假阳性理论=%.4f" %
      (ALPHA, M_TESTS, theory))
print("蒙特卡洛 %d 次: 未校正假阳性率=%.4f (最小 p 平均=%.4f)" %
      (REPS, raw / REPS, minp_sum / REPS))
print("Bonferroni 阈值=%.6f 校正后假阳性率=%.4f" %
      (ALPHA / M_TESTS, corrected / REPS))
print("真实效应 delta=%.2f, n=%d 时检出率(功效)=%.4f" %
      (TRUE_EFFECT, N, hits / REPS))
print("理论 z≈delta*sqrt(n)/sigma=%.4f" % (TRUE_EFFECT * math.sqrt(N)))

操作：把 M_TESTS 改成 1、5、20，观察假阳性率如何随尝试次数上升；把 TRUE_EFFECT 改成 0.1 看功效下降。　预期与判读：df=98 时 t 临界值≈1.984；m=20 的理论假阳性率≈0.6415，未校正模拟≈0.68（多次检验共享同一 y，略有相关）；Bonferroni 阈值 0.0025 后≈0.034（略保守）；δ=0.3、n=100 时功效≈0.83（理论 z≈3）。

改参数看趋势：M_TESTS 越大假阳性越严重；TRUE_EFFECT 或 N 越小功效越低；ALPHA 决定整条曲线。　文件位置：part6/31-reproducibility/code/31-reproducibility.py

§常见误区

  • 把 p<0.05 当成「效应为真」的概率：它只描述原假设下的尾部概率。
  • 只汇报最终设定：探索过程中的每一次尝试都应披露或预注册。
  • 忽略功效：低功效研究的显著效应量往往被严重高估。
