给程序员的翻译

§2.1期望、方差与条件期望

随机变量 Y 的期望 E[Y] 是概率加权平均，方差 Var(Y)=E[(Y−E[Y])²] 描述离散。三个恒等式贯穿全书：

Var(aX+bY) = a²Var(X) + b²Var(Y) + 2ab·Cov(X,Y)

E[Y] = E[ E[Y|X] ] (迭代期望定律)

Var(Y) = E[Var(Y|X)] + Var(E[Y|X]) (方差分解)

迭代期望定律是 第 21 章 · 最小二乘：手写 OLS、标准误与高斯-马尔可夫 证明 OLS 无偏、第 23 章 · 内生性与工具变量：2SLS 的手写实现 说明工具变量、第 30 章 · 期权、二叉树与蒙特卡洛：无套利定价的闭环 用蒙特卡洛定价时反复用的工具；方差分解则直接对应 第 27 章 · 均值-方差组合：分散化与有效前沿 的「分散化降低组合方差」与 第 22 章 · 诊断与修正：异方差、自相关与共线性 的异方差。

§2.2LLN、CLT 与标准误

设 Y₁,…,Yₙ 独立同分布，均值 μ、方差 σ²。样本均值 Ȳ 满足：

大数定律: Ȳ → μ ; 中心极限定理: √n(Ȳ−μ)/σ ⇒ N(0,1)

于是 Ȳ 的标准误是 σ/√n，约 95% 的重复样本会落在 μ ± 1.96σ/√n 内。置信区间的频率学含义是「重复抽样下的覆盖率」，不是「真参数有 95% 概率落在本次区间里」。

程序员最容易误读的地方：1.96 来自正态近似，样本小或分布重尾时覆盖率会失真；第 31 章 · 复现、多重检验与研究规范 会展示「多试几次就能凑出显著结果」的 p-hacking 机制。

§2.3把 DGP 写成代码

一个 DGP 要显式写清三件事：随机变量分布、变量之间的结构关系、哪些量被观测到。本书所有计量章节都先写出 DGP，再由它生成数据，最后检查估计量能否把已知参数找回来——这相当于给估计器写「已知答案的单元测试」。

§Python 建模实例

大数定律、中心极限定理与 95% 覆盖率

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""02-clt.py | 固定种子的重复抽样实验：LLN / CLT / 标准误"""
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
N = 25                 # 每个样本的观测数
REPS = 4000            # 重复抽样次数
CONF_Z = 1.96          # 正态近似 95% 临界值
# ---- DGP: Y ~ U(0,1)，mu=0.5，sigma^2=1/12 ----
mu, sigma = 0.5, math.sqrt(1.0 / 12.0)
means = []
for _ in range(REPS):
    draws = [random.random() for _ in range(N)]
    means.append(statistics.fmean(draws))
avg = statistics.fmean(means)
sd = statistics.pstdev(means)
se_theory = sigma / math.sqrt(N)
cover = sum(1 for m in means if abs(m - mu) <= CONF_Z * se_theory) / REPS
# ---- 数值验证：打印可手算核对的量 ----
rng = random.Random(7)
first3 = [rng.random() for _ in range(3)]
print("前 3 个随机数(固定种子): %.6f %.6f %.6f" % tuple(first3))
print("理论 mu=%.6f sigma=%.6f 标准误=%.6f" % (mu, sigma, se_theory))
print("重复抽样均值均值=%.6f 均值标准差=%.6f" % (avg, sd))
print("95%% 置信区间实际覆盖率=%.4f (理论约 0.95)" % cover)
print("n=25 时区间半宽=%.6f" % (CONF_Z * se_theory))

操作：把 N 依次改成 4、25、400，观察标准差是否按 1/√n 缩小。　预期与判读：μ=0.5、σ≈0.288675、n=25 时标准误≈0.057735；重复抽样均值≈0.5，其标准差≈0.0577，覆盖率≈0.95，区间半宽≈0.11316。

改参数看趋势：N 变大 → 标准误按 1/√N 缩小；REPS 变大 → 覆盖率估计更稳定；CONF_Z 改成 2.576 得到 99% 覆盖率。　文件位置：part0/02-probability-simulation/code/02-clt.py

§常见误区

  • 把标准误当成样本标准差：前者是估计量在重复抽样下的离散程度，差一个 √n。
  • 把 95% 置信区间解释成「真值有 95% 概率在此区间」：频率学含义是覆盖率。
  • 不固定随机种子就汇报数值结果：别人无法复现，也就无法审计。
