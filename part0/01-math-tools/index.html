§1.1从网格搜索到一阶条件

00 章用网格暴力枚举可行组合。枚举法直观但不可扩展：变量一多就是维度灾难。经济学标准做法是把问题写成

max_x f(x; θ) s.t. g(x; θ) ≤ 0 ; L(x,λ;θ) = f(x;θ) − λ·g(x;θ)

在 interior solution（内点解）与凹性成立时，最优解满足一阶条件（FOC）：

∂f/∂x = λ·∂g/∂x , g(x;θ) = 0 , λ ≥ 0

λ 是影子价格：把约束放松一个单位（预算多 1 元、排放配额多 1 吨）最优值能增加多少。这个解释在 第 12 章 · 外部性、公共品与科斯谈判 的庇古税、第 14 章 · 一般均衡与加总：微观部分的收口 的一般均衡、第 27 章 · 均值-方差组合：分散化与有效前沿 的组合前沿里都原样复用。

二阶条件（SOC）负责排除「一阶导为零但其实是极小值或鞍点」的情况：单变量看二阶导为负，多变量看海塞矩阵负定。经济模型里通常靠凹目标 + 凸可行集一次保证全局最优，这也是 Cobb-Douglas、对数效用被反复使用的原因。

§1.2比较静态：参数怎么影响解

比较静态问的是「θ 变了，最优解 x*(θ) 往哪走」，不是「经济如何随时间走过去」（那是动态，见 第 18 章 · 长期增长：索洛稳态、条件收敛与内生增长）。做法是把恒成立的 FOC 对 θ 求导：

F(x*(θ), θ) ≡ 0 ⇒ dx*/dθ = − (∂F/∂θ) / (∂F/∂x)

符号判断往往比数值更重要：需求定律说价格上升需求量下降，本质是 FOC 里分母为负、分子为正。包络定理给出更省事的结果：求最优值对参数的导数时，只需对拉格朗日函数直接求偏导，x* 的间接变动在最优处一阶抵消：

dV(θ)/dθ = ∂L(x*, λ*; θ)/∂θ

这条定理在 第 05 章 · 消费者理论：偏好、需求与希克斯分解 推导支出函数、第 29 章 · 债券、久期与期限结构：利率风险的一阶与二阶 计算久期（价格对利率的敏感度）时都省掉大量求导。

§1.3数值求解：手写一个二分法

很多模型没有闭式解，但 FOC 是单调函数时可以用二分法。下面的脚本求解 Cobb-Douglas 效用下的最优需求，并与解析解 x* = αB/pₓ 对照；同时打印 λ 作为「预算的边际效用」。

数值习惯：先把有解析解的模型算一遍，确认数值方法可信，再把它用到没有解析解的模型上。这是本书所有模拟脚本的固定套路。

§Python 建模实例

二分法解一阶条件 + 影子价格

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""01-lagrange.py | FOC 数值求解、比较静态与影子价格"""
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
B, PX, PY, ALPHA = 100.0, 2.0, 5.0, 0.5
TOL_ITER = 80
# ---- 模型：MRS = (a/(1-a))*(y/x)，最优时 MRS = p_x/p_y ----
def y_of(x):
    return (B - PX * x) / PY

def mrs(x):
    return (ALPHA / (1 - ALPHA)) * (y_of(x) / x)

lo, hi = 1e-9, B / PX - 1e-9
for _ in range(TOL_ITER):
    mid = (lo + hi) / 2
    if mrs(mid) > PX / PY:      # x 偏小，MRS 偏高，需增大 x
        lo = mid
    else:
        hi = mid
x = (lo + hi) / 2
y = y_of(x)
u = (x ** ALPHA) * (y ** (1 - ALPHA))
lam = ALPHA * (x ** (ALPHA - 1)) * (y ** (1 - ALPHA)) / PX
# ---- 比较静态：预算增加 1 元时效用增加多少 ----
dB = 1.0
B2 = B + dB
x2 = ALPHA * B2 / PX
y2 = (1 - ALPHA) * B2 / PY
u2 = (x2 ** ALPHA) * (y2 ** (1 - ALPHA))
# ---- 数值验证：打印可手算核对的量 ----
print("FOC 数值解 x=%.6f y=%.6f MRS=%.6f p比=%.6f" % (x, y, mrs(x), PX / PY))
print("解析解     x=%.6f y=%.6f" % (ALPHA * B / PX, (1 - ALPHA) * B / PY))
print("最大效用 u=%.6f  影子价格 lambda=%.6f" % (u, lam))
print("预算+1 的效用增益=%.6f (包络定理预测=%.6f)" % (u2 - u, lam * dB))

操作：运行后把 PX 改成 4，观察 x、MRS 与 λ 的变化方向；这就是比较静态。　预期与判读：x=25、y=10、MRS=0.4=pₓ/pᵧ；u≈15.8114；λ≈0.158114，预算增加 1 元的效用增益≈0.158114，与包络定理一致。

改参数看趋势：PX 上升 → x 下降、λ 上升；ALPHA 上升 → x 份额上升；TOL_ITER 控制二分精度。　文件位置：part0/01-math-tools/code/01-lagrange.py

§常见误区

  • 把 λ 当成「价格」本身：它是目标函数对约束松紧的边际价值，单位随目标函数而定。
  • 忽略二阶条件：FOC 只是驻点条件，非凹目标时可能停在极小值。
  • 把比较静态当成动态调整：前者比较两个均衡，后者研究均衡之间的路径。
