给程序员的翻译

把经济学想成一个分层系统：偏好与技术是「配置」，价格与均衡是「运行时调度」，市场失灵是「约束不满足」，计量是「从日志反推系统参数」，投资是「在噪声环境下做在线决策」。

学习目标
  • 能说清全书主线「稀缺 → 选择 → 均衡 → 效率 → 失灵 → 动态 → 不确定 → 证据 → 决策」
  • 知道每个阶段的输出物：可推导的模型、可运行的模拟、可复现的估计、可检验的决策
  • 掌握固定的四步学习闭环：读模型 → 跑代码 → 改参数 → 写结论

§0.1为什么这几门课其实是同一门课

常见课程表把「原理、微观、宏观、计量、投资」拆成五门课，容易让人误以为是五套互不相干的工具。本书从一个反复出现的计算问题出发把它们接起来：

给定资源、技术与信息 → 求一个可行的最优选择 → 研究许多人同时选择时是否自洽（均衡）

把这句话逐层放大，就得到全书主线：

环节要回答的问题对应课程对应篇章
稀缺与选择在约束下最优是什么经济学原理卷首、第一篇 03～08
均衡与效率个体最优同时成立吗？结果好不好微观经济学第二篇 09～14
动态与总量把时间、货币、增长、开放加进来宏观经济学第三篇 15～19
证据与识别模型参数能不能从观测数据里求出来计量经济学第四篇 20～25
不确定与决策未来是分布而非确定值时怎么下注投资学第五篇 26～30
方法论与综合结论可信吗？如何端到端做完一个课题研究实践第六篇 31～32

关键在于同一个数学骨架反复出现：约束最优化（消费者、生产者、组合选择）、不动点（均衡、纳什、一般均衡、稳态）、条件期望（回归、资产定价）、以及「反事实」（因果推断、政策评估、期权 payoff）。学会识别这四种骨架，五门课就变成五种应用配置。

§0.2五个学习阶段与本书结构

  1. 第一阶段 · 个体、市场与效率（00～14）：先把「选择」写成可解的数学问题，再研究多人互动的均衡与失灵，最后用一般均衡收口微观。
  2. 第二阶段 · 总量、货币与增长（15～19）：把「加总」当成一个新问题而不是简单求和，处理核算恒等式、短期波动、长期增长与开放经济。
  3. 第三阶段 · 数据与因果识别（20～25）：从模拟出的数据生成过程出发，手写 OLS、诊断、IV、DID 与时间序列，回答「什么条件下估计量等于因果参数」。
  4. 第四阶段 · 不确定性与资产定价（26～30）：把随机收益、组合优化、因子模型、利率期限结构与无套利定价接成一条链。
  5. 第五阶段 · 综合与方法论（31～32、附录）：多重检验与复现规范，最后用一个端到端课题把全部环节跑通。

§0.3模型的三层用法：解释、预测、反事实

同一个模型有三种用法，混淆它们是初学阶段最常见的错误：

用法问句需要的前提本书对应
解释（正推）给定参数，均衡会是什么样模型设定正确03～19 章的模拟
预测（外推）未来一期最可能是什么结构稳定、分布不变25、26、30 章
反事实（干预）若政策改成 t，结果会变多少识别假设成立，参数不随干预改变20～24、31 章

卢卡斯批判是第三层的陷阱：若政策改变了人们形成预期的方式，用历史数据拟合出的参数就不能直接拿来做反事实。程序员的类比是：训练集分布与部署分布不一致时，离线指标再好也不能推断线上效果。

§Python 建模实例

最小可运行脚本：稀缺下的最优选择

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""00-hello-econ.py | 第一个经济程序：把「选择」写成约束最优化"""
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
BUDGET = 100.0          # 预算
PX, PY = 2.0, 5.0       # 两种商品的价格
ALPHA = 0.5             # Cobb-Douglas 效用中 x 的份额
GRID = 100              # 网格精度
# ---- 模型：u(x,y) = x^a * y^(1-a)，约束 p_x*x + p_y*y = B ----
best = (-1.0, 0.0, 0.0)
for i in range(GRID + 1):
    x = BUDGET / PX * i / GRID
    y = (BUDGET - PX * x) / PY
    u = (x ** ALPHA) * (y ** (1 - ALPHA))
    if u > best[0]:
        best = (u, x, y)
# ---- 解析解（后面第 05 章会推导）----
analytic_x = ALPHA * BUDGET / PX
analytic_y = (1 - ALPHA) * BUDGET / PY
# ---- 数值验证：打印可手算核对的量 ----
print("预算=%.2f 价格=(%.2f, %.2f) a=%.2f" % (BUDGET, PX, PY, ALPHA))
print("网格最优 x=%.2f y=%.2f u=%.4f" % (best[1], best[2], best[0]))
print("解析最优 x=%.2f y=%.2f" % (analytic_x, analytic_y))
print("支出校验=%.2f (应等于预算)" % (PX * best[1] + PY * best[2]))

操作：直接运行 python3 part0/00-preface/code/00-hello-econ.py；把 ALPHA 改成 0.3 观察最优组合怎么移动。　预期与判读：网格最优 x=25.00、y=10.00、u≈15.8114；解析解同为 25 与 10；支出 100 恰好用尽预算。

改参数看趋势：ALPHA 越大越偏好 x；PX 上升使 x 的需求按 αB/PX 下降；GRID 决定数值解与解析解的接近程度。　文件位置：part0/00-preface/code/00-hello-econ.py

代码块右上角可一键复制；仓库里的 code/*.py 由 tools/extract_code.py 从这些代码块自动抽取。脚本只用标准库、固定 random.seed(7)，批量运行用 ./tools/run_python.sh。

§常见误区

  • 把拟合优度当成因果证据：相关与反事实是两件事，第 20 章会正式处理。
