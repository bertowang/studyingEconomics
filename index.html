本书的主张

四种数学骨架反复出现：约束最优化（消费者、企业、组合）、不动点（均衡、纳什、稳态）、条件期望（回归、资产定价）、反事实（因果推断、政策评估、期权 payoff）。认出骨架，五门课就变成五种应用配置。

每章学习闭环固定为四步：读模型 → 跑代码 → 改参数 → 写结论；每个脚本都用已知真值的数据生成过程，把估计结果和真值并列打印，相当于带答案的单元测试。

运行 Python 示例（30 秒）

  1. 需要 Python 3.8+，不需要安装任何第三方包：示例只用 math、random、statistics 等标准库。
  2. 直接运行某一章脚本：python3 part1/04-supply-demand/code/04-supply-demand.py；或从页面代码块右上角「复制」。
  3. 批量验证全部示例：./tools/run_python.sh；只跑某几个：./tools/run_python.sh part4/21-ols/code/21-ols.py。
  4. 页面里的代码块与磁盘上的 code/*.py 由 tools/extract_code.py 自动同步，永远一致。
给程序员的代码契约
  • 零依赖：矩阵求逆、OLS、稳健标准误、二叉树定价全部手写展开，方便对照公式。
  • 自包含：数据由脚本里的「数据生成过程」合成，不下载、不读外部文件。
  • 可复现：固定 random.seed(7)；参数集中在 # ---- 参数区 ----。
  • 数值可核对：结尾 print 打印可手算的量，页面给出预期值与判读。
  • 可批量验证：./tools/run_python.sh 跑完全部脚本；python3 tools/check_book.py --run 把实跑纳入自检。

为什么不用 numpy / statsmodels？因为教材要展示的是算法本身。附录 A.5 给出手写实现与工业库的对照表，学完之后应能无缝切换到成熟工具。

学习路线（建议两个学期）

  1. 第一阶段 · 个体、市场与效率（00～14）：约束最优化、供需与弹性、消费者/生产者、贸易与风险、福利定理、垄断与博弈、外部性与信息、一般均衡。
  2. 第二阶段 · 总量、货币与增长（15～19）：国民账户、乘数与 IS-LM、泰勒规则、索洛稳态、国际收支与汇率。
  3. 第三阶段 · 数据与因果识别（20～25）：潜在结果 → 手写 OLS → 稳健标准误 → IV/2SLS → DID 与固定效应 → 平稳性与伪回归。
  4. 第四阶段 · 不确定性与资产定价（26～30）：收益与复利 → 有效前沿 → CAPM 与因子 → 久期与期限结构 → 二叉树 / Black-Scholes / 蒙特卡洛。
  5. 第五阶段 · 综合与方法论（31～32、附录）：多重检验与复现规范，最后用一个端到端政策评估课题把全部环节跑通。

时间有限时的最短路径：01 → 04 → 09 → 20 → 21 → 24 → 27 → 30 → 32。
