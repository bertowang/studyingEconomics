§5.1偏好 → 效用 → 需求

偏好若满足完备性、传递性与连续性，就能用效用函数 u(x,y) 表示；效用只保序，基数大小没有意义。最常用的 Cobb-Douglas 形式：

u(x,y) = x^α · y^(1−α) , 0<α<1 ; MRS = MU_x/MU_y = (α/(1−α))·(y/x)

在预算 pₓx + pᵧy = B 下令 MRS 等于价格比，得到马歇尔需求：

x* = αB/pₓ , y* = (1−α)B/pᵧ , v(p,B) = B·(α/pₓ)^α·((1−α)/pᵧ)^(1−α)

注意 x* 只花掉固定比例 α 的收入——这是 Cobb-Douglas 的特殊性质，不是一般规律。它使需求的价格弹性恰为 −1，收入弹性恰为 1，便于手算核对。

§5.2对偶问题：支出最小化

把同一个最优问题反过来问：达到给定效用 u 最少要花多少钱？这就是支出最小化，其解 h(p,u) 称为希克斯需求（补偿需求）：

e(p,u) = min p·x s.t. u(x) ≥ u ; h_i(p,u) = ∂e(p,u)/∂p_i (谢泼德引理)

对 α=1/2，可解析求出 e(p,u)=2u√(pₓpᵧ)、hₓ=u√(pᵧ/pₓ)。由包络定理还能得到 ∂v/∂pᵢ = −λ·xᵢ 与 ∂v/∂B = λ，相除即罗伊恒等式。这些对偶关系让「从需求反推偏好」成为可能，也是 第 29 章 · 债券、久期与期限结构：利率风险的一阶与二阶 久期、第 27 章 · 均值-方差组合：分散化与有效前沿 前沿中「敏感度即导数」的同构。

§5.3价格变化：斯勒茨基分解与货币化福利

价格上升对需求的总影响可以拆成两部分：

Δx = [h(p₁,u₀) − h(p₀,u₀)] + [x(p₁,B) − h(p₁,u₀)] = 替代效应 + 收入效应

替代效应沿同一条无差异曲线移动，必为负（相对变贵的商品少买）；收入效应反映实际购买力下降，方向取决于商品是正常品还是劣等品。吉芬品即收入效应强到压过替代效应的极端情形。

把效用变化折算成钱，有两种约定：

CV = B − e(p₀,u₁) (按旧价格补偿) ; EV = e(p₁,u₀) − B (按新价格等价)

二者一般不等，因为计价的「汇率」（价格向量）不同；对拟线性偏好才恒等。政策评估里选哪个取决于要回答「涨价为补偿需要补多少钱」还是「涨价相当于收入减少多少」。

§Python 建模实例

需求、支出函数、CV/EV 与斯勒茨基分解

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 05-consumer.py | Cobb-Douglas 需求的对偶计算（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
B = 100.0
PX0, PY = 2.0, 5.0
PX1 = 3.0              # x 涨价
ALPHA = 0.5
# ---- 马歇尔需求与间接效用 ----
def demand(px, py, b):
    return ALPHA * b / px, (1 - ALPHA) * b / py

def utility(x, y):
    return (x ** ALPHA) * (y ** (1 - ALPHA))

# ---- 支出函数与希克斯需求（alpha=0.5 的解析式）----
def expenditure(px, py, u):
    return u * (px / ALPHA) ** ALPHA * (py / (1 - ALPHA)) ** (1 - ALPHA)

def hicks_x(px, py, u):
    return u * (py / px) ** (1 - ALPHA)

x0, y0 = demand(PX0, PY, B)
x1, y1 = demand(PX1, PY, B)
u0, u1 = utility(x0, y0), utility(x1, y1)
cv = B - expenditure(PX0, PY, u1)
ev = expenditure(PX1, PY, u0) - B
sub = hicks_x(PX1, PY, u0) - hicks_x(PX0, PY, u0)
inc = x1 - hicks_x(PX1, PY, u0)
# ---- 数值验证：打印可手算核对的量 ----
print("旧价需求 x0=%.4f y0=%.4f u0=%.4f" % (x0, y0, u0))
print("新价需求 x1=%.4f y1=%.4f u1=%.4f" % (x1, y1, u1))
print("支出函数校验 e(p0,u0)=%.4f (应=B=%.2f)" % (expenditure(PX0, PY, u0), B))
print("CV=%.4f  EV=%.4f  (涨价损失，EV>CV 因新价计价更高)" % (cv, ev))
print("总效应=%.4f = 替代效应 %.4f + 收入效应 %.4f" % (x1 - x0, sub, inc))

操作：把 ALPHA 改成 0.3，观察 CV/EV 与替代效应如何变化；把 PX1 改成 2.5 观察分解是否仍成立。　预期与判读：x0=25、y0=10、u0≈15.8114；x1≈16.6667、u1≈12.9099；e(p0,u0)=100；CV≈18.3503、EV≈22.4745；总效应 −8.3333 = 替代 −4.5876 + 收入 −3.7457。

改参数看趋势：PX1 越接近 PX0，CV 与 EV 越接近；ALPHA 越大，涨价带来的福利损失越大。　文件位置：part1/05-consumer-choice/code/05-consumer.py

§常见误区

  • 把效用当作可人际比较的基数：它只表示排序，单调变换不改变需求。
  • 把 CV 与 EV 混用：两者计价价格不同，只有拟线性偏好才相等。
  • 以为替代效应可能为正：希克斯需求对自身价格单调不增，符号由对偶性保证。
