§8.1跨期：现值、年金与欧拉方程

一笔未来现金流 C_t 的现值是 C_t/(1+r)^t；等额年金可求和为闭式：

PV = C·[1 − (1+r)^(−T)] / r ; 永续 PV = C/r

两期消费者最大化 u(c₁) + β·u(c₂)，预算 c₁ + c₂/(1+r) ≤ y₁ + y₂/(1+r)，一阶条件即欧拉方程：

u'(c₁) = β(1+r)·u'(c₂) ; 对数效用下 c₂/c₁ = β(1+r)

读法：β(1+r) 大于 1 时把消费推到明天（耐心或高利率），小于 1 时提前消费。宏观的 第 16 章 · 短期波动：乘数、IS-LM 与 AD-AS 消费函数、第 17 章 · 货币政策、通胀与利率：费雪方程与泰勒规则 实际利率、第 18 章 · 长期增长：索洛稳态、条件收敛与内生增长 储蓄率与增长都由这条式子在不同约束下推出；第 29 章 · 债券、久期与期限结构：利率风险的一阶与二阶 债券定价则是它的直接应用。

§8.2风险：期望效用与确定性等价

不确定下不最大化期望财富，而最大化期望效用（冯·诺依曼–摩根斯坦公理）：

EU = Σ p_s·u(w_s) ; CE 满足 u(CE) = EU ; 风险溢价 RP = E[w] − CE

由 Jensen 不等式，u 凹 ⇒ E[u(w)] ≤ u(E[w]) ⇒ CE ≤ E[w] ⇒ 风险溢价非负。风险厌恶的局部度量是 A(w)=−u''/u'（阿罗–普拉特）；对数效用 A=1/w，财富越高越不怕小赌。

与 第 27 章 · 均值-方差组合：分散化与有效前沿 的接口：均值-方差准则等价于「效用二次 或 收益正态」下的期望效用近似，因此 E[r] − (A/2)Var(r) 里的风险系数不是随手加的惩罚项，而是凹效用的二阶展开。

§8.3用蒙特卡洛核对解析结果

脚本同时用解析式与固定种子的随机抽样计算确定性等价：ln 效用下 CE = exp(E[ln w])，即财富的几何平均。这给出了本书第一次「模拟估计一个已知量」的闭环，第 30 章 · 期权、二叉树与蒙特卡洛：无套利定价的闭环 会把它放大成期权定价的主力方法。

§Python 建模实例

现值、欧拉方程、确定性等价与蒙特卡洛

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 08-risk.py | 跨期贴现与期望效用（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
C_ANNUAL, RATE, YEARS = 100.0, 0.05, 20
BETA = 0.95
W_LOW, W_HIGH, P_HIGH = 80.0, 120.0, 0.5
N_DRAWS = 20000
# ---- 跨期：年金现值 ----
pv = C_ANNUAL * (1 - (1 + RATE) ** (-YEARS)) / RATE
perpetuity = C_ANNUAL / RATE
c_ratio = BETA * (1 + RATE)     # 对数效用下 c2/c1
# ---- 风险：解析期望效用 ----
eu = (1 - P_HIGH) * math.log(W_LOW) + P_HIGH * math.log(W_HIGH)
ce = math.exp(eu)
expected_w = (1 - P_HIGH) * W_LOW + P_HIGH * W_HIGH
rp = expected_w - ce
# ---- 蒙特卡洛核对 ----
draws = [W_HIGH if random.random() < P_HIGH else W_LOW for _ in range(N_DRAWS)]
mc_mean = statistics.fmean(draws)
mc_ce = math.exp(statistics.fmean([math.log(w) for w in draws]))
# ---- 数值验证：打印可手算核对的量 ----
print("年金现值(T=%d)=%.4f  永续现值=%.4f" % (YEARS, pv, perpetuity))
print("欧拉方程 c2/c1=beta*(1+r)=%.4f" % c_ratio)
print("EU=%.6f  CE=%.6f (=sqrt(80*120)=%.6f)" % (eu, ce, math.sqrt(W_LOW * W_HIGH)))
print("E[w]=%.4f  风险溢价 RP=%.4f" % (expected_w, rp))
print("蒙特卡洛: 平均财富=%.4f  几何平均(CE)=%.4f  与解析差=%.4f" %
      (mc_mean, mc_ce, mc_ce - ce))

操作：把 W_LOW/W_HIGH 的价差拉大（如 40/160），观察 RP 如何上升；把 BETA 改成 1.0 看 c₂/c₁。　预期与判读：20 年年金现值≈1246.22、永续=2000；c₂/c₁=0.9975；CE=√9600≈97.9796、RP≈2.0204；蒙特卡洛几何平均≈98 左右，与解析值一致。

改参数看趋势：价差越大 RP 越大；P_HIGH 偏离 0.5 会改变 CE；BETA 上升使消费后移。　文件位置：part1/08-risk-time/code/08-risk.py

  • 把期望财富最大化当决策准则：凹效用下应最大化期望效用。
