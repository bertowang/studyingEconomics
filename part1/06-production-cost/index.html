§6.1技术与边际产量

设 y = A·K^α·L^(1−α)。短期 K 固定，劳动的边际产量递减：

MP_L = ∂y/∂L = (1−α)·A·K^α·L^(−α) , ∂MP_L/∂L < 0

若所有投入同乘 t，产出乘 t^(α+1−α)=t，即规模报酬不变；指数之和大于 1 为递增、小于 1 为递减。这一条指数和直接决定 第 18 章 · 长期增长：索洛稳态、条件收敛与内生增长 索洛模型能否有稳态，也决定长期平均成本是否 U 形。

§6.2成本最小化与成本曲线

成本最小化 min wL + rK s.t. f(K,L) ≥ y 的一阶条件是技术替代率等于要素价格比：

MP_L/MP_K = w/r ; MC(y) = ∂C(y)/∂y = w/MP_L (短期 K 固定)

因为 MP_L 递减，MC 递增；MC 穿过 AVC 与 ATC 的最低点（「平均值被边际值拉动」的算术事实）。固定成本不影响 MC，因此短期产量决策与固定成本无关——这是容易被会计直觉带偏的一点。

§6.3利润最大化与供给

价格接受型企业解 max_L p·f(K,L) − wL − rK，一阶条件：

p·MP_L = w ⇔ p = MC(y)

所以短期供给曲线就是 MC 曲线在 AVC 最低点之上的部分；低于 AVC 时停业更划算。长期自由进入退出使价格压到 ATC 最低点，经济利润为零——与 第 03 章 · 稀缺、机会成本与生产可能性边界 的机会成本定义闭环。把个体供给横向加总，就得到 第 04 章 · 供需、弹性与税收归宿：第一个均衡 的市场供给。

研究生视角：利润函数 π(p,w,r)=max py−C(y) 对 p 求导即供给（霍特林引理），对 w 求导的负数是要素需求（谢泼德引理的对偶版本）。第 29 章 · 债券、久期与期限结构：利率风险的一阶与二阶 久期、第 05 章 · 消费者理论：偏好、需求与希克斯分解 希克斯需求与此完全同构：值函数对价格的导数就是净需求。

§Python 建模实例

生产、成本曲线与利润最大化的数值验证

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 06-cost.py | 短期生产函数、MC=p 条件与规模报酬（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
A_PROD, K_FIXED = 2.0, 16.0     # y = A * sqrt(K) * sqrt(L)
WAGE, FIXED_COST = 4.0, 20.0
PRICE = 10.0
GRID = 1000
# ---- 模型 ----
def output(l, k=K_FIXED):
    return A_PROD * math.sqrt(k) * math.sqrt(l)

def mp_l(l, k=K_FIXED):
    return 0.5 * A_PROD * math.sqrt(k) / math.sqrt(l)

def profit(l):
    return PRICE * output(l) - WAGE * l - FIXED_COST

best_l, best_pi = 0.0, profit(0.0)
for i in range(1, GRID + 1):
    l = 200.0 * i / GRID
    if profit(l) > best_pi:
        best_l, best_pi = l, profit(l)
# p*MP_L=w 的解析解: L = (p*A*sqrt(K)/(2w))^2
analytic_l = (PRICE * A_PROD * math.sqrt(K_FIXED) / (2 * WAGE)) ** 2
q = output(best_l)
mc = WAGE / mp_l(best_l)
ac = (WAGE * best_l + FIXED_COST) / q
# ---- 数值验证：打印可手算核对的量 ----
print("网格最优 L=%.4f 产量=%.4f 利润=%.4f" % (best_l, q, best_pi))
print("解析解   L=%.4f (由 p*MP_L=w 解出)" % analytic_l)
print("最优处 MC=%.4f (应=p=%.2f)  AC=%.4f" % (mc, PRICE, ac))
print("MP_L(L=1)=%.4f, MP_L(L=100)=%.4f → 递减" % (mp_l(1.0), mp_l(100.0)))
print("规模报酬: 投入翻倍 y 由 %.2f 到 %.2f (比值 %.2f)" %
      (output(25.0, 16.0), output(50.0, 32.0), output(50.0, 32.0) / output(25.0, 16.0)))

操作：把 PRICE 改成 5，观察最优 L 是否按 p² 缩小；把 FIXED_COST 改成 200，观察产量是否不变。　预期与判读：L*=100、y=80、利润=380；MC=10=p；AC=5.25；MP_L 从 4.0 降到 0.4；投入翻倍产量恰好翻倍（规模报酬不变）。

改参数看趋势：PRICE 上升 → L* 按 p² 增长；FIXED_COST 只影响利润不影响产量；WAGE 上升压缩利润并提高 MC。　文件位置：part1/06-production-cost/code/06-cost.py

§常见误区

  • 把固定成本算进边际决策：停业点由 AVC 决定，与已沉没的固定成本无关。
  • 把会计利润当经济利润：后者要扣除资本与自有劳动的机会成本。
  • 把规模报酬与边际报酬递减混为一谈：前者是所有投入一起变，后者是单一投入变、其他固定。
