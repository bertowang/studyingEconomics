第 03 章稀缺、机会成本与生产可能性边界

经济学第一原理：资源有限而用途很多，选择的真实成本是被放弃的最优替代用途。生产可能性边界把这句话画成一条可计算的曲线。

给程序员的翻译

PPF 就是资源调度器的可行域边界：边界上是「CPU 时间全部用满」，内部是「有闲置」，外部是「超配不可调度」。边界斜率是两种任务之间的实时兑换率。

学习目标
  • 能计算机会成本并说明它为什么不是会计成本
  • 会从劳动与技术参数推导线性 / 外凸的生产可能性边界
  • 理解边际转换率递增与「专业化不是无限制的」

§3.1机会成本才是成本

会计成本记录「花了多少钱」，经济成本记录放弃的最好的其他用途。用自己的店面开店，账面上没有租金，但机会成本是把店面租出去能拿到的租金；程序员辞职创业的「零工资」同样不是零成本。

经济利润 = 收入 − 显性成本 − 隐性成本(机会成本)

因此「零经济利润」并不意味着没赚钱，而是刚好赚到与次优用途一样多；这正是 第 09 章 · 福利经济学：剩余、效率与两条福利定理 里完全竞争长期均衡的条件。

§3.2从技术参数推导 PPF

设总劳动 L，生产一单位食品需 a_F 工时、一单位布需 a_C 工时，线性技术下：

a_F·F + a_C·C ≤ L ⇒ C = (L − a_F·F)/a_C , 斜率 dC/dF = −a_F/a_C = 常数

此时机会成本是常数，PPF 是直线。若每种产品存在边际报酬递减（例如 F = √L_F、C = √L_C），则

PPF 外凸: 斜率绝对值 |dC/dF| 随 F 增大而增大 = 边际转换率 MRT 递增

直觉：把越来越多的资源从布转到食品，每一次转移要放弃的布越来越多。外凸 PPF 是「为什么现实中很少完全专业化」的技术原因，也为 第 07 章 · 比较优势、专业化与贸易收益 的贸易收益设定了上限。

§3.3可行、有效与不可行

位置含义对应计算概念
边界内资源闲置或配置低效，可在不减少任一产品时增加另一产品可行解但非 Pareto 最优
边界上技术有效：要多一单位 F 必须少一些 C约束起作用的 Pareto 前沿
边界外现有技术不可达；只有技术进步 / 资本积累才能外移不可行域；见 第 18 章 · 长期增长：索洛稳态、条件收敛与内生增长

注意 PPF 只回答「能不能生产」，不回答「该生产多少」；后者需要偏好（第 05 章 · 消费者理论：偏好、需求与希克斯分解）与价格（第 04 章 · 供需、弹性与税收归宿：第一个均衡）。

§Python 建模实例

线性与外凸 PPF：机会成本怎么变

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""03-ppf.py | 从劳动与技术参数计算 PPF 与边际转换率"""
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
L = 100.0              # 总劳动
A_F, A_C = 2.0, 4.0   # 单位产品耗用工时
POINTS = 5
# ---- 模型 1: 线性技术，机会成本为常数 ----
def linear_c(f):
    return (L - A_F * f) / A_C

# ---- 模型 2: 边际报酬递减 F=sqrt(L_f), C=sqrt(L-L_f) ----
def bowed_c(f):
    used = f * f
    return math.sqrt(max(0.0, L - used))

def mrt(f, h=1e-4):
    return (bowed_c(f) - bowed_c(f + h)) / h
# ---- 数值验证：打印可手算核对的量 ----
print("线性 PPF: F=0 时 C=%.2f；F=%.2f 时 C=0" % (linear_c(0.0), L / A_F))
print("线性机会成本 dC/dF = -a_F/a_C = %.4f (常数)" % (-A_F / A_C))
print("外凸 PPF: F=0 时 C=%.2f；F=%.2f 时 C=0" % (bowed_c(0.0), math.sqrt(L)))
for i in range(POINTS):
    f = 2.0 * i + 1.0
    print("  F=%4.1f  C=%7.4f  MRT=%8.4f" % (f, bowed_c(f), mrt(f)))
print("检验预算约束: 2*10+4*20 = %.1f (应等于 L)" % (A_F * 10 + A_C * 20))

操作：把 A_F 改成 1.0，先预测线性 PPF 截距与斜率如何变化，再运行核对。　预期与判读：线性 PPF 截距 C=25、F=50，机会成本恒为 −0.5；外凸 PPF 截距 C=10、F=10；MRT 绝对值从 F=1 时的 0.10 单调增大到 F=9 时的 2.06。

改参数看趋势：L 增大使整条 PPF 外移；A_F 增大使 F 的最大产量下降、机会成本上升；POINTS 只影响打印密度。　文件位置：part1/03-scarcity-ppf/code/03-ppf.py

§常见误区

  • 把会计成本当机会成本：自有资源不出现在账本上，却真实影响决策。
  • 以为 PPF 外凸是「曲线好看」：它来自边际报酬递减，是有技术含义的。
  • 把边界上的点都当成社会最优：技术有效不等于满足消费者偏好。
