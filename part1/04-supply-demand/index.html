第 04 章供需、弹性与税收归宿：第一个均衡

局部均衡是全书第一个「不动点」：价格调整到需求量等于供给量。弹性决定谁承担税负，无谓损失量化扭曲的代价。

给程序员的翻译

均衡价格就是让 excess_demand(p)=Qd(p)−Qs(p) 归零的根；税收是在买方价与卖方价之间插入一个 6 元的「楔子」，等价于给求解器加一条约束。

  • 解释「税负落在弹性小的一侧」并会用数字验证

§4.1均衡作为不动点

设需求 Q_d = a − b·p、供给 Q_s = c + d·p（a,b,c,d > 0）。令超额需求为零：

p* = (a − c)/(b + d) , Q* = a − b·p* = c + d·p*

稳定性直觉：若 p > p*，供给大于需求，卖不掉的库存迫使价格下降；反之价格上升。这其实是一个最简单的迭代求解器，第 14 章 · 一般均衡与加总：微观部分的收口 的一般均衡会把它升级成多市场价格向量的不动点问题。

§4.2弹性：量纲无关的响应度

弹性用百分比变化之比，因而与单位无关：

ε_d = (dQ_d/dp)·(p/Q) ; ε_s = (dQ_s/dp)·(p/Q)

弹性是比较静态的局部导数，会随均衡点移动；线性需求在高价区更富弹性。政策分析特别依赖弹性：需求缺乏弹性时，加税主要落在消费者身上；供给缺乏弹性时主要落在生产者身上。

§4.3单位税：楔子、归宿与无谓损失

对每单位商品征税 t，买方价 p_c 与卖方价 p_s 满足 p_c − p_s = t。联立线性供需可得：

p_s = (a − c − b·t)/(b + d) , p_c = p_s + t , Q_t = a − b·p_c

消费者承担份额 = d/(b+d) ; 生产者承担份额 = b/(b+d)

税收收入 T = t·Q_t ; 无谓损失 DWL = ½·t·(Q* − Q_t)

注意归宿与法定纳税人无关：向卖家征税和向买家征税得到同一个楔子。弹性小的一侧「更离不开市场」，因而被套牢。无谓损失是三角形面积：被税收挤掉的交易本来双方都愿意做，这部分互利的消失是净福利损失，不是转移支付。

推广到 第 12 章 · 外部性、公共品与科斯谈判：把外部成本看成「社会边际成本比私人边际成本高一截」，庇古税正是用同样的楔子把这块差额内部化；区别在于那里税是为了纠正扭曲，而不是制造扭曲。

§Python 建模实例

均衡、弹性、单位税与无谓损失

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""04-supply-demand.py | 线性供需的均衡与税收归宿全量核算"""
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
A, B, C, D = 100.0, 2.0, 10.0, 3.0    # Qd=A-B*p, Qs=C+D*p
TAX = 6.0                              # 单位税
# ---- 模型：无税均衡 ----
p0 = (A - C) / (B + D)
q0 = A - B * p0
ed = -B * p0 / q0
es = D * p0 / q0
# ---- 比较静态：征税后 ----
ps = (A - C - B * TAX) / (B + D)
pc = ps + TAX
qt = A - B * pc
revenue = TAX * qt
dwl = 0.5 * TAX * (q0 - qt)
consumer_share = (pc - p0) / TAX
producer_share = (p0 - ps) / TAX
# ---- 数值验证：打印可手算核对的量 ----
print("无税: p*=%.4f Q*=%.4f 需求弹性=%.4f 供给弹性=%.4f" % (p0, q0, ed, es))
print("征税: 买方价=%.4f 卖方价=%.4f 楔子=%.4f Q=%.4f" % (pc, ps, pc - ps, qt))
print("消费者承担=%.4f 生产者承担=%.4f (理论 %.4f / %.4f)" %
      (consumer_share, producer_share, D / (B + D), B / (B + D)))
print("税收收入=%.4f 无谓损失=%.4f 总剩余损失=%.4f" % (revenue, dwl, revenue + dwl))
print("校验: 无税 Qs=%.4f, 征税 Qs=%.4f, 征税 Qd=%.4f" % (C + D * p0, C + D * ps, qt))

操作：把 D 改成 8（供给更富弹性），观察消费者承担份额是否上升；把 TAX 改成 12 观察 DWL 是否按 t² 增长。　预期与判读：p*=18、Q*=64、ε_d=−0.5625、ε_s=0.84375；征税后 ps=15.6、pc=21.6、Q=56.8；消费者承担 0.6、生产者 0.4；税收 340.8、DWL 21.6。

改参数看趋势：D 越大（供给越弹性）消费者承担越多；TAX 翻倍使 DWL 约变 4 倍；B 越大需求越弹性、数量下降越多。　文件位置：part1/04-supply-demand/code/04-supply-demand.py

§常见误区

  • 以为「向谁征税」决定谁承担：法定归宿与经济归宿是两回事。
  • 把税收收入当作社会损失：它是转移支付，真正的净损失是 DWL。
  • 用斜率代替弹性：斜率带单位，弹性是无量纲的百分比响应度，跨市场比较必须用弹性。
