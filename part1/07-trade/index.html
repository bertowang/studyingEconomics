贸易收益来自机会成本的差异，而不是绝对生产率的高低；世界价格落在两国机会成本之间时，双方都能消费到超出本国 PPF 的组合。

给程序员的翻译

比较优势就是「按相对吞吐率分配任务」：即使一台机器样样都快，也该把稀缺资源投到它相对优势最大的任务上；调度依据是相对成本比，不是绝对耗时。

学习目标
  • 能由单位劳动投入计算两国机会成本并判定比较优势
  • 会构造世界价格并验证进出口与市场出清
  • 解释为什么贸易收益是「消费可能性外移」而不是「多生产了所有商品」

§7.1绝对优势不是贸易的理由

李嘉图模型里，两国各有一种固定技术 aᵢⱼ（生产一单位商品 j 所需工时），劳动总量 L。自给自足的相对价格就是本国 PPF 斜率：

(p_F/p_C)_A = a_AF/a_AC , (p_F/p_C)_B = a_BF/a_BC

只要这两个比值不同，就存在比较优势。即使 A 国两种商品都更省工（绝对优势全占），贸易仍对双方有利，因为资源配置看的是「放弃什么」，不是「干得多快」。

§7.2世界价格与贸易收益

设 A 国食品机会成本为 1、B 国为 0.25。开放后世界相对价格 p_F/p_C 必落在 [0.25, 1] 之间；在此区间内 A 专业化生产布、B 专业化生产食品。用出口收入按世界价格买回另一种商品，两国消费组合都落在各自 PPF 之外：

消费可能性: p_F·F + p_C·C ≤ p_C·(L/a_AC) (A 国专业化生产布时的预算线)

这是全书第一个「约束被交换放宽」的例子：不是技术进步，而是允许交换使可行集外移。第 09 章 · 福利经济学：剩余、效率与两条福利定理 的福利定理会说清它在什么条件下成立，第 12 章 · 外部性、公共品与科斯谈判、第 13 章 · 信息不对称：逆向选择、信号与道德风险 则说明市场缺失或信息不对称时收益会打折。

§7.3收益不等于人人受益

层次结论前提 / 限制
两国总量贸易使双方总消费可能性扩大技术差异、无运输成本、完全竞争
国内分配相对价格变化使稀缺要素受益、密集使用该要素的部门收缩要素可流动需要时间，短期有调整成本
长期增长贸易可能通过技术扩散影响增长率超出李嘉图静态模型，见 第 18 章 · 长期增长：索洛稳态、条件收敛与内生增长

把「总量收益」直接说成「每个人都变好」是常见逻辑跳跃；补偿原则说的是赢家理论上足以补偿输家，不等于补偿真的发生。

§Python 建模实例

两国两商品：机会成本、专业化与市场出清

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 07-trade.py | 李嘉图模型的贸易收益（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
L = 100.0
A_AF, A_AC = 2.0, 2.0      # A 国: 食品/布 单位工时
A_BF, A_BC = 1.0, 4.0      # B 国
WORLD_PF = 0.5             # 世界相对价格 p_F/p_C，p_C=1
SHARE = 0.5                # 收入中用于食品的份额（Cobb-Douglas）
# ---- 机会成本与比较优势 ----
oc_a = A_AF / A_AC
oc_b = A_BF / A_BC
# ---- 自给自足：收入一半买食品、一半买布 ----
fa = SHARE * L / A_AF
ca = SHARE * L / A_AC
fb = SHARE * L / A_BF
cb = SHARE * L / A_BC
# ---- 专业化 + 贸易 ----
# A 生产布，B 生产食品；世界价格必须落在两国机会成本之间
q_c_world = L / A_AC
q_f_world = L / A_BF
value_a = q_c_world * 1.0
value_b = q_f_world * WORLD_PF
f_a = SHARE * value_a / WORLD_PF
c_a = SHARE * value_a / 1.0
f_b = SHARE * value_b / WORLD_PF
c_b = SHARE * value_b / 1.0
# ---- 数值验证：打印可手算核对的量 ----
def u(f, c):
    return math.sqrt(f * c)
print("机会成本: A=%.4f  B=%.4f  世界价=%.4f 在区间内=%s" %
      (oc_a, oc_b, WORLD_PF, min(oc_a, oc_b) <= WORLD_PF <= max(oc_a, oc_b)))
print("自给自足 A=(%.2f, %.2f) u=%.4f ; B=(%.2f, %.2f) u=%.4f" %
      (fa, ca, u(fa, ca), fb, cb, u(fb, cb)))
print("贸易后   A=(%.2f, %.2f) u=%.4f ; B=(%.2f, %.2f) u=%.4f" %
      (f_a, c_a, u(f_a, c_a), f_b, c_b, u(f_b, c_b)))
print("市场出清: 食品需求=%.2f 供给=%.2f ; 布需求=%.2f 供给=%.2f" %
      (f_a + f_b, q_f_world, c_a + c_b, q_c_world))
print("A 出口布=%.2f 进口食品=%.2f" % (q_c_world - c_a, f_a))

操作：把 WORLD_PF 改成 0.9（更靠近 A 国机会成本），观察收益如何在两国之间重新分配。　预期与判读：A 国机会成本 1、B 国 0.25，世界价 0.5 落在区间内；自给自足 A=(25,25)、B=(50,12.5)，效用均 25；贸易后两国均为 (50,25)，效用≈35.36；两个市场都恰好出清。

改参数看趋势：WORLD_PF 越接近某国自给自足价格，该国贸易收益越小；A_BC 下降会缩小两国技术差异与收益。　文件位置：part1/07-trade/code/07-trade.py

§常见误区

  • 把绝对优势当成贸易原因：关键是比较机会成本，不是绝对生产率。
  • 以为世界价格可以任意设定：必须落在两国机会成本之间，否则至少一国不愿专业化。
  • 把总量收益说成人人受益：部门间要素再配置会产生受损者。
