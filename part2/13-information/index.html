给程序员的翻译

逆向选择是「输入数据分布随筛选规则漂移」：按价格过滤卖家会改变剩下样本的质量分布，进而改变合理价格，形成正反馈。信号是可验证但无生产性的开销，等价于成本高到低类型不愿伪造的认证。

§13.1逆向选择：价格改变样本构成

Akerlof 模型：二手车质量 q 在 [0, Q̄] 上均匀分布，卖家保留价值 αq（α<1），买家估值 γq（γ>1）。给定价格 p，只有 q ≤ p/α 的车主愿意卖，于是买家面对的平均质量是 q̄(p)=p/(2α)，愿意付的最高价是 γ·q̄(p)=γp/(2α)。

自洽条件: p = γ·p/(2α) ⇒ 若 γ/(2α) < 1，唯一解是 p = 0（市场完全消失）

关键在于不是需求不足，而是价格本身决定了谁留在市场里。质量的平均被不断向下修正，形成反身性循环。保修、第三方检测、品牌与平台评价，都是把 q 变成可观测信息的制度。

§13.2信号：用成本差异把类型分开

Spence 模型里教育不提高生产率，只提高可观测程度。设两类生产率 θ_L=1、θ_H=2，教育成本 e/θ（高能力者更省力），工资等于市场对类型的期望生产率。分离均衡要同时满足：

低类型不冒充: θ_H − e/θ_L ≤ θ_L ⇒ e ≥ 1

高类型愿意选: θ_H − e/θ_H ≥ θ_L ⇒ e ≤ 2

于是 e∈[1,2] 都构成分离均衡。注意教育支出是纯社会成本：它不改变产出，只改变信息。这是「私人理性、社会浪费」的经典例子，也说明均衡不唯一、制度细节（谁先行动、信念如何形成）会影响结果。

§13.3道德风险：签约后的隐藏行动

问题信息在何时不对称典型解法
逆向选择签约前，类型（风险高低）隐藏筛查、信号、分级定价
道德风险签约后，行动（是否谨慎、是否努力）隐藏免赔额、共保、绩效合约

全额保险使投保人对损失无感，从而不采取防损行动；留一部分风险（deductible）恢复了边际激励，代价是风险分担变差。委托代理模型把它形式化为激励相容约束 + 参与约束下的次优合约：信息租金与风险分担之间存在可计算的权衡。

与计量的接口：第 23 章 · 内生性与工具变量：2SLS 的手写实现 的工具变量、第 24 章 · 面板与准实验：DID、固定效应与断点回归 的 DID 都在处理「处理组不是随机分配的」；而「谁选择投保、谁选择交易」本身就是选择行为，忽略它就会把选择效应误判成因果效应。

§Python 建模实例

柠檬市场收敛与信号分离区间

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 13-information.py | 逆向选择的价格-质量反馈与 Spence 信号（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
Q_MAX = 100.0        # 质量上界
ALPHA = 0.8          # 卖家保留价值 = alpha * q
GAMMA = 1.2          # 买家估值 = gamma * q
P_START = 60.0
STEPS = 12
THETA_L, THETA_H = 1.0, 2.0
# ---- 柠檬市场：迭代 p <- gamma * E[q | alpha*q <= p] ----
def avg_quality(p):
    cutoff = min(Q_MAX, p / ALPHA)
    return cutoff / 2.0

p = P_START
trace = [p]
for _ in range(STEPS):
    p = GAMMA * avg_quality(p)
    trace.append(p)
ratio = GAMMA / (2 * ALPHA)
# ---- 信号：分离均衡的教育区间 ----
e_low = THETA_H - THETA_L                 # 低类型不冒充的下界
e_high = THETA_H * (THETA_H - THETA_L)   # 高类型愿意选的上界
check_low = THETA_H - e_low / THETA_L    # 冒充所得
check_high = THETA_H - e_low / THETA_H   # 选择所得
# ---- 数值验证：打印可手算核对的量 ----
print("参数: alpha=%.2f gamma=%.2f 收敛因子 gamma/(2 alpha)=%.4f" % (ALPHA, GAMMA, ratio))
print("价格迭代(前 6 步): " + " -> ".join("%.4f" % x for x in trace[:6]))
print("第 %d 步价格=%.8f (收敛因子<1 时趋于 0)" % (STEPS, trace[-1]))
print("分离均衡教育区间 e ∈ [%.2f, %.2f]" % (e_low, e_high))
print("e=1 时低类型冒充所得=%.2f (=不冒充的工资 %.2f)" % (check_low, THETA_L))
print("e=1 时高类型净所得=%.2f (>低类型工资 %.2f)" % (check_high, THETA_L))

操作：把 GAMMA 改成 2.0（买家更看重质量），观察收敛因子大于 1 时价格迭代是否还收敛到 0。　预期与判读：α=0.8、γ=1.2 时收敛因子 0.75，价格从 60 按 0.75 倍递减并趋于 0；分离均衡教育区间 e∈[1,2]；e=1 时低类型冒充所得 1，恰好等于不冒充的工资。

改参数看趋势：GAMMA 上升到 1.6 以上时因子≥1，市场不再必然 unravel；ALPHA 越大（卖家越惜售）市场越可能存活。　文件位置：part2/13-information/code/13-information.py

§常见误区

  • 把市场萎缩归咎于买家「不识货」：即使信息结构清晰，均衡也可能不存在非零交易。
  • 把信号成本当成生产性投资：分离均衡里教育只传递信息，是净社会成本。
  • 混淆逆向选择与道德风险：前者是签约前隐藏类型，后者是签约后隐藏行动。
