给程序员的翻译

外部性就是函数调用的副作用没有被计入成本：调用方只看自己的开销，系统总开销更高。庇古税是给副作用定一个价格并计入账；科斯方案是让受影响双方直接协商并内部化。

学习目标
  • 能量化负外部性造成的过度产量与无谓损失
  • 推导庇古税 t = 边际外部损害，并验证它恢复社会最优
  • 说明科斯定理的前提与交易成本、公共品搭便车的失败机制

§12.1外部性：从私人最优到社会最优

设反需求 p = a − bQ、私人边际成本 c、每单位外部损害 e。竞争均衡令 p = c，社会最优令 p = c + e：

Q_0 = (a−c)/b , Q* = (a−c−e)/b , 超额产量 = e/b

外部性造成的福利损失 = ∫_{Q*}^{Q_0} [(c+e) − p(q)] dq = ½·e·(e/b) = e²/(2b)

注意价格低本身不是问题，问题是多生产的那些单位上社会成本高于支付意愿。庇古税 t = e 把生产者面对的边际成本抬到 c+e，市场在不指定产量的情况下自行走到 Q*——这正是「用价格改约束、不用命令改结果」的思路。

§12.2科斯定理：产权、谈判与交易成本

科斯定理说：若产权清晰、交易成本为零、无收入效应，则无论产权初始判给谁，双方谈判都会达到有效产量（只是分配不同）。它的价值不在于证明「政府不必干预」，而在于把注意力转向交易成本：

现实条件后果对应工具
受影响者众多组织与搭便车成本高庇古税 / 总量管制与交易
损害难计量谈判缺乏共同事实监测、披露、标准
收入效应显著产权分配影响最终结果需结合公平目标评估

排放权交易（cap-and-trade）是两者混合：先由政府定总量，再由市场定价，等价于让科斯谈判在一个标准化、可分割的产权上发生。

§12.3公共品：加总支付意愿而非加总数量

私人品的最优条件是每人 MRS = MRT；公共品非竞争，一人消费不减少他人消费，因此萨缪尔森条件是纵向加总：

Σ_i MRS_i = MRT （n 人各自边际支付意愿之和 = 边际成本）

自愿捐赠时每人只把自己的边际收益与成本比较，均衡总量远低于社会最优，且人数越多缺口越大。这与 第 11 章 · 博弈论与寡头：策略互动与不动点 囚徒困境完全同构：搭便车是占优策略。

§Python 建模实例

庇古税、科斯交易成本与公共品供给

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 12-externality.py | 外部性内部化与公共品搭便车（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
A, B, C_PRIV, DAMAGE = 100.0, 2.0, 10.0, 12.0
TRANSACTION_COST = 2.0       # 科斯谈判的单位组织成本
N_PERSONS = 3                # 公共品人数
PG_INTERCEPT, PG_COST = 20.0, 12.0
# ---- 竞争均衡与社会最优 ----
q0 = (A - C_PRIV) / B
q_opt = (A - C_PRIV - DAMAGE) / B
ext_loss = DAMAGE ** 2 / (2 * B)
tax_revenue = DAMAGE * q_opt
q_taxed = (A - C_PRIV - DAMAGE) / B
# ---- 科斯：谈判净收益与交易成本 ----
gross_gain = DAMAGE * (q0 - q_opt) - 0.5 * B * (q0 - q_opt) ** 2
net_gain = gross_gain - TRANSACTION_COST * (q0 - q_opt)
# ---- 公共品：私人自愿 vs 萨缪尔森条件 ----
# 每人 MRS_i = 20 - G, 边际成本 = 12
g_private = PG_INTERCEPT - PG_COST                    # 20 - G = 12
g_social = (N_PERSONS * PG_INTERCEPT - PG_COST) / N_PERSONS / 1.0  # n*(20-G)=12
# ---- 数值验证：打印可手算核对的量 ----
print("私人 MC=%.2f 社会 MC=%.2f (含损害 %.2f)" % (C_PRIV, C_PRIV + DAMAGE, DAMAGE))
print("竞争 Q0=%.4f 社会最优 Q*=%.4f 超额=%.4f" % (q0, q_opt, q0 - q_opt))
print("外部性福利损失=%.4f (=e^2/2b)" % ext_loss)
print("庇古税 t=%.2f 后产量=%.4f (应=Q*) 税收=%.4f" % (DAMAGE, q_taxed, tax_revenue))
print("科斯谈判总增益=%.4f 扣交易成本后净增益=%.4f" % (gross_gain, net_gain))
print("公共品自愿总量=%.4f 社会最优总量=%.4f 缺口=%.4f" %
      (g_private, g_social, g_social - g_private))

操作：把 DAMAGE 改成 24，观察 Q* 与外部性损失（应变为 4 倍）；把 TRANSACTION_COST 调大看科斯谈判何时失效。　预期与判读：Q0=45、Q*=39、超额 6；损失 36；庇古税 12 后产量 39、税收 468；科斯毛增益 36、净增益 24；公共品自愿总量 8、社会最优 16、缺口 8。

改参数看趋势：DAMAGE 翻倍使 DWL 变 4 倍；N_PERSONS 越大公共品缺口越大；交易成本超过边际增益时谈判破裂。　文件位置：part2/12-externality/code/12-externality.py

§常见误区

  • 把庇古税当成「为罚款而罚款」：税额应等于边际外部损害，不是弥补财政缺口。
  • 忽略税收收入与损害减少是两笔账：评估福利要同时算产量、损害与转移。
  • 把科斯定理读成「产权无关紧要」：产权决定分配，且交易成本为零这个前提极强。
