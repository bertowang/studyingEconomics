给程序员的翻译

垄断者是在自己的需求曲线上做一维最大化：多卖一单位得到的边际收益 = 价格 − 因降价损失的老客户收入。价格歧视是「按用户分组做分段计价」，本质是把消费者剩余转成生产者剩余。

  • 比较统一价格与三级价格歧视下的产量、利润与福利

§10.1边际收益与最优产量

设反需求 p = a − bQ、恒定边际成本 c。收益 R = aQ − bQ²，故

MR = a − 2bQ ; MR = c ⇒ Q_m = (a−c)/(2b) , p_m = (a+c)/2

竞争均衡满足 p = c，产量 Q_c = (a−c)/b = 2Q_m。垄断把价格抬到 MC 之上，交易量减少，DWL 是需求与 MC 之间被挤掉的三角形。

把 FOC 改写可得勒纳指数：

(p − MC)/p = −1/ε_d ⇒ |ε_d| 必须大于 1（垄断者永不在缺乏弹性区生产）

这条式子把「 markup 」与「替代难度」直接挂钩：需求越缺乏弹性（替代品越少），加价越狠。它是反垄断中界定市场势力、第 28 章 · CAPM 与因子模型：什么风险该有补偿 中理解定价因子的常用近似。

§10.2三级价格歧视

若企业能分割两个市场且无法套利，就分别令 MR₁ = MR₂ = MC，等价于：

p_i·(1 − 1/|ε_i|) = MC ⇒ 弹性小的市场定价更高

与统一价格相比，歧视定价通常会提高利润；总产量是否增加不确定，因此福利结论也不是一边倒：若它打开了原本服务不到的市场，可能同时提高产出与福利。判断标准是总产量，不是「是否区别定价」。

§10.3自然垄断与规制的两难

规制方式做法问题
边际成本定价p = MC若 AC 递减，企业亏损，需补贴
平均成本定价p = AC零利润但仍有 DWL
回报率规制按成本加合理利润缺乏降本激励（A-J 效应）
两部定价入门费 + p = MC需要能阻止套利、识别需求

共同主题：信息不对称下的机制设计。规制者不知道真实成本曲线，企业有动机夸大成本——这正是 第 13 章 · 信息不对称：逆向选择、信号与道德风险 的委托代理问题。

§Python 建模实例

垄断、勒纳指数与三级价格歧视

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 10-monopoly.py | MR=MC、弹性加价与分组定价（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
A, B, MC = 100.0, 2.0, 10.0     # 单市场反需求 p=A-B*Q
M1 = (100.0, 2.0)               # 市场 1: (a, b)
M2 = (80.0, 4.0)                # 市场 2
GRID = 20000
# ---- 单市场：竞争 / 垄断 ----
qc = (A - MC) / B
qm = (A - MC) / (2 * B)
pm = A - B * qm
profit_m = (pm - MC) * qm
cs_m = 0.5 * qm * (A - pm)
dwl = 0.5 * (pm - MC) * (qc - qm)
eps = -pm / (B * qm)
lerner = (pm - MC) / pm
# ---- 统一价格 vs 分别定价（两市场，MC 相同）----
def total_q(p):
    return sum(max(0.0, (a - p) / b) for a, b in (M1, M2))
best_p, best_pi = MC, 0.0
for i in range(GRID + 1):
    p = MC + (A - MC) * i / GRID
    pi = (p - MC) * total_q(p)
    if pi > best_pi:
        best_p, best_pi = p, pi
sep = []
for a, b in (M1, M2):
    q = (a - MC) / (2 * b)
    sep.append((q, a - b * q, (a - b * q - MC) * q))
sep_profit = sum(x[2] for x in sep)
# ---- 数值验证：打印可手算核对的量 ----
print("竞争 Q=%.4f p=%.4f" % (qc, MC))
print("垄断 Q=%.4f p=%.4f 利润=%.4f" % (qm, pm, profit_m))
print("垄断 CS=%.4f DWL=%.4f" % (cs_m, dwl))
print("需求弹性=%.4f 勒纳指数=%.4f 1/|eps|=%.4f" % (eps, lerner, 1 / abs(eps)))
print("统一价格 p=%.4f 利润=%.4f 总产量=%.4f" % (best_p, best_pi, total_q(best_p)))
for i, (q, p, pi) in enumerate(sep, 1):
    print("  市场%d 分别定价 q=%.4f p=%.4f 利润=%.4f" % (i, q, p, pi))
print("歧视总利润=%.4f 增量=%.4f" % (sep_profit, sep_profit - best_pi))

操作：把 M2 的斜率改成 2.0（两市场弹性相同），观察歧视定价的利润增量是否趋于零。　预期与判读：竞争 Q=45、p=10；垄断 Q=22.5、p=55、利润 1012.5、DWL=506.25；ε≈−1.2222、勒纳指数≈0.8182=1/|ε|；统一价≈51.67 利润≈1302.08，分别定价利润=1318.75，增量≈16.67。

改参数看趋势：B 越小需求越弹性、加价越低；MC 上升压缩产量；两市场需求弹性越接近，歧视收益越小。　文件位置：part2/10-monopoly/code/10-monopoly.py

§常见误区

  • 把 MR 当成价格：降价卖出的额外一单位会压低所有旧单位的收入，MR 低于 p。
  • 断言价格歧视一定降低福利：结论取决于总产量是否增加。
  • 在需求缺乏弹性区间谈垄断均衡：FOC 会自动排除 |ε|≤1 的点。
