§11.1纳什均衡作为不动点

在标准式博弈中，策略组合 s* 满足

u_i(s*_i, s*_{−i}) ≥ u_i(s_i, s*_{−i}) 对所有 i 与所有 s_i

纳什均衡不保证集体最优：囚徒困境里双方都选择背叛，是唯一的纳什均衡，却帕累托劣于双方合作。这与 第 09 章 · 福利经济学：剩余、效率与两条福利定理 福利第一定理形成对照——那里个体之间只通过价格间接联系，这里收益直接耦合。

§11.2古诺双寡头：从最优反应到均衡

设反需求 p = a − b(q₁+q₂)、边际成本 c。企业 i 解 max (p−c)q_i，得最优反应：

q_i = (a − c − b·q_j)/(2b) ; 对称均衡 q* = (a−c)/(3b) , Q* = 2(a−c)/(3b)

产量排序：Q_垄断 = (a−c)/2b < Q*_古诺 < Q_竞争 = (a−c)/b；价格与利润同向排序。把每家企业的最优反应看成一次映射，反复迭代就是在求这个映射的不动点——与 第 14 章 · 一般均衡与加总：微观部分的收口 求解价格向量、第 18 章 · 长期增长：索洛稳态、条件收敛与内生增长 求解稳态 k*=s·f(k*) 是同一套数值思想。

§11.3重复博弈：合作何时能自我维持

有限次重复且阶段博弈有唯一均衡时，逆向归纳仍给出每期背叛。无限次重复则不同：触发策略（一旦有人背叛就永远回到纳什惩罚）可持续，当

π_C/(1−δ) ≥ π_D + δ·π_N/(1−δ) ⇔ δ ≥ (π_D−π_C)/(π_D−π_N)

δ 是贴现因子（见 第 08 章 · 跨期选择与不确定下的决策），衡量「未来有多重要」；合作收益 π_C、背叛一次性收益 π_D、惩罚期收益 π_N。制度、声誉、长期关系的作用，就是把 δ 有效抬高。这也解释了 第 12 章 · 外部性、公共品与科斯谈判 公共品自愿供给为什么在小社区里比匿名大社会更容易维持。

§Python 建模实例

纳什均衡、古诺迭代与重复博弈阈值

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 11-games.py | 最优反应迭代与触发策略（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
A, B, C = 100.0, 1.0, 10.0
ITERS = 60
PD = {("C", "C"): (3, 3), ("C", "D"): (0, 5),
      ("D", "C"): (5, 0), ("D", "D"): (1, 1)}
# ---- 囚徒困境：逐个检查是否为纳什均衡 ----
acts = ["C", "D"]
nash = []
for s1 in acts:
    for s2 in acts:
        stable = all(PD[(s1, s2)][0] >= PD[(t, s2)][0] for t in acts) and \
                 all(PD[(s1, s2)][1] >= PD[(s1, t)][1] for t in acts)
        if stable:
            nash.append((s1, s2))
# ---- 古诺：最优反应迭代 ----
def br(qj):
    return max(0.0, (A - C - B * qj) / (2 * B))
q1 = q2 = 0.0
history = []
for _ in range(ITERS):
    n1, n2 = br(q2), br(q1)
    history.append((n1, n2))
    q1, q2 = n1, n2
q_star = (A - C) / (3 * B)
price = A - B * (q1 + q2)
pi_each = (price - C) * q1
# ---- 重复博弈：合作 / 背叛 / 惩罚收益 ----
q_coop = (A - C) / (2 * B) / 2          # 两家平分垄断产量
pi_c = (A - B * (2 * q_coop) - C) * q_coop
q_dev = br(q_coop)                       # 对方合作时的最优背叛
pi_d = (A - B * (q_dev + q_coop) - C) * q_dev
pi_n = pi_each
delta_min = (pi_d - pi_c) / (pi_d - pi_n)
# ---- 数值验证：打印可手算核对的量 ----
print("囚徒困境纳什均衡:", nash, " 支付=", PD[nash[0]])
print("古诺迭代第1轮=(%.4f, %.4f) 第2轮=(%.4f, %.4f)" %
      (history[0][0], history[0][1], history[1][0], history[1][1]))
print("迭代收敛 q=%.6f  解析解=%.6f  价格=%.4f  单家利润=%.4f" % (q1, q_star, price, pi_each))
print("垄断/古诺/竞争总产量=%.2f / %.2f / %.2f" %
      ((A - C) / (2 * B), 2 * q_star, (A - C) / B))
print("合作收益=%.4f 背叛收益=%.4f 惩罚收益=%.4f" % (pi_c, pi_d, pi_n))
print("触发策略可持续所需 delta >= %.4f" % delta_min)

操作：把 ITERS 改成 3，观察同步最优反应迭代的振荡；把 A 改成 200 看 δ 阈值是否变化。　预期与判读：纳什均衡为 (D,D)，支付 (1,1)；古诺迭代从 (45,45)→(22.5,22.5) 逐步收敛到 30；价格 40、单家利润 900；总产量 45/60/90；合作收益 1012.5、背叛收益≈1139.06、δ 阈值≈0.5294。

改参数看趋势：A 或 C 改变只影响规模，δ 阈值主要由需求线性结构决定；ITERS 体现迭代收敛速度。　文件位置：part2/11-games-oligopoly/code/11-games.py

§常见误区

  • 把纳什均衡等同于集体最优：囚徒困境是最直接的的反例。
  • 把最优反应迭代的收敛当成必然：某些博弈同步迭代会震荡或发散，需要阻尼或异质更新。
  • 忽略子博弈精炼：有限次重复博弈里的「威胁」未必可信。
