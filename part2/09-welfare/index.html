§9.1剩余是可计算的福利

把需求曲线理解为边际支付意愿、供给曲线理解为边际成本，则交易第 q 单位带来的净剩余是 p_d(q) − p_s(q)：

CS = ∫₀^Q [p_d(q) − p] dq ; PS = ∫₀^Q [p − p_s(q)] dq ; TS = ∫₀^Q [p_d(q) − p_s(q)] dq

价格只是 CS 与 PS 之间的转移，不改变 TS；改变交易量才改变 TS。因此无谓损失总可以写成「被挤掉的那段交易上边际支付意愿与边际成本之差的积分」——第 04 章 · 供需、弹性与税收归宿：第一个均衡 的三角形公式是线性曲线下的特例。

§9.2价格管制：短缺、配置与 DWL

设上限 p̄ < p*，则 Q_s(p̄) < Q_d(p̄)，实际成交量是短边 Q̄ = min(Q_d, Q_s)。此时「谁买到」变得关键：

配给方式实际成交福利结果
有效配给（支付意愿最高者买到）Q_s(p̄)DWL = TS(Q*) − TS(Q̄)
随机配给 / 排队Q_s(p̄)额外损失：错配 + 排队耗散的租
黑市 / 变相收费可能接近 Q*名义价格失效，租转移给中间人

这解释了为什么单看「价格低了」判断不了政策好坏：必须说明成交量、配置规则与租的归属。第 12 章 · 外部性、公共品与科斯谈判 的庇古税同样是插楔子，但那个楔子把原本未被计入的成本内部化，方向恰好相反。

§9.3两条福利定理及其前提

第一定理：在完全竞争、完备市场、无外部性、无信息不对称、凸技术下，竞争均衡是帕累托有效的。第二定理：在上述条件加凸偏好下，任一帕累托有效分配都可通过对初始禀赋的一次性再分配 + 竞争市场实现。

两个定理都不是「市场万能」的证明，而是一份前提清单：第 10 章 · 市场势力：垄断定价、勒纳指数与价格歧视 打破价格接受，第 11 章 · 博弈论与寡头：策略互动与不动点 引入策略互动，第 12 章 · 外部性、公共品与科斯谈判 引入外部性与公共品，第 13 章 · 信息不对称：逆向选择、信号与道德风险 引入私有信息。第二定理还常被误读：它说的是一次性 lump-sum 再分配，现实中的所得税会扭曲边际激励（回到 第 04 章 · 供需、弹性与税收归宿：第一个均衡 的楔子）。效率与公平是可分离的问题，但只在极强假设下可分离。

§Python 建模实例

剩余积分、价格上限与无谓损失

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 09-welfare.py | 从反供需曲线积分计算福利（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
A, B, C, D = 100.0, 2.0, 10.0, 3.0    # Qd=A-B*p, Qs=C+D*p
CEILING = 14.0                         # 价格上限
# ---- 反需求 / 反供给及其原函数 ----
def pd(q):
    return (A - q) / B

def ps(q):
    return (q - C) / D

def int_pd(q):
    return (A * q - q * q / 2) / B

def int_ps(q):
    return (q * q / 2 - C * q) / D

def ts(q):
    return int_pd(q) - int_ps(q)

p0 = (A - C) / (B + D)
q0 = A - B * p0
cs0 = int_pd(q0) - p0 * q0
psi0 = p0 * q0 - int_ps(q0)
# ---- 价格上限：成交取短边 ----
qs = C + D * CEILING
qd = A - B * CEILING
qt = min(qd, qs)
cs_t = int_pd(qt) - CEILING * qt
ps_t = CEILING * qt - int_ps(qt)
dwl = ts(q0) - ts(qt)
# ---- 数值验证：打印可手算核对的量 ----
print("均衡 p*=%.4f Q*=%.4f" % (p0, q0))
print("均衡 CS=%.4f PS=%.4f TS=%.4f" % (cs0, psi0, ts(q0)))
print("上限 p=%.2f: Qs=%.2f Qd=%.2f 短缺=%.2f 成交=%.2f" % (CEILING, qs, qd, qd - qs, qt))
print("管制后 CS=%.4f PS=%.4f TS=%.4f" % (cs_t, ps_t, ts(qt)))
print("无谓损失=%.4f  三角公式=%.4f" %
      (dwl, 0.5 * (pd(qt) - ps(qt)) * (q0 - qt)))
print("检验: 上限处反供给=%.4f (应等于上限)" % ps(qs))

操作：把 CEILING 改成 18（等于均衡价），观察 DWL 是否归零；改成 10 观察短缺与 DWL 如何放大。　预期与判读：p*=18、Q*=64；CS=1024、PS=682.6667、TS=1706.6667；上限 14 时 Qs=52、Qd=72、短缺 20，CS=1196、PS=450.6667、DWL=60，与三角公式一致。

改参数看趋势：CEILING 越低于均衡价，短缺按 (B+D)·(p*−p̄) 增大，DWL 按缺口平方增长。　文件位置：part2/09-welfare/code/09-welfare.py

§常见误区

  • 把价格管制下的需求量当成交量：市场按短边成交，出现的是短缺而非超额供给。
  • 忽略配给规则：随机配给会在 DWL 之外再叠加错配与排队成本。
  • 引用福利第二定理时忽略 lump-sum 假设：现实再分配工具本身会制造楔子。
