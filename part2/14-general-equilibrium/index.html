给程序员的翻译

一般均衡是求一个全局价格向量使所有市场的 excess_demand 同时为零；瓦尔拉斯法则说明这些方程有一个恒等依赖，因此自由度少一维，可以固定一个计价物（numeraire）。

  • 用二分法求均衡相对价格并验证两个市场同时出清
  • 解释瓦尔拉斯法则与合成谬误，说明微观到宏观为何需要额外假设

§14.1从个体需求到市场超额需求

两人两商品纯交换经济：消费者 i 有禀赋 ω_i、Cobb-Douglas 份额 α_i，收入 m_i = p·ω_i，需求 x_i1 = α_i m_i/p₁、x_i2 = (1−α_i)m_i/p₂。市场 j 的超额需求：

z_j(p) = Σ_i x_ij(p) − Σ_i ω_ij ; z(p*)=0 为竞争均衡

因为需求对价格零次齐次（所有价格同乘不改变预算与需求），只有相对价格有意义；固定 p₁=1，用一维搜索解 z₁(r)=0（r=p₂/p₁）即可。

§14.2瓦尔拉斯法则与数值求解

每个消费者的预算约束恒成立，加总得到

p₁z₁(p) + p₂z₂(p) ≡ 0 对任意价格向量成立

所以若 z₁=0，必有 z₂=0；只需解 n−1 个市场。数值上可以用二分法或 tâtonnement（超额需求为正就抬价），后者的收敛性并非自动保证——Sonnenschein–Mantel–Debreu 定理说明，加总超额需求除了连续性、零次齐次与瓦尔拉斯法则外几乎不继承个体理性带来的良好性质。这是「代表性个体」假设必须额外论证的原因。

§14.3加总陷阱：合成谬误

微观结论直接加总会怎样宏观需要的修正
个体多储蓄更富裕全体同时多储蓄 → 总需求下降、收入下降储蓄悖论，见 第 16 章 · 短期波动：乘数、IS-LM 与 AD-AS 乘数
单个企业降价抢份额所有企业降价 → 价格水平下降而非份额变化区分相对价格与价格水平，第 17 章 · 货币政策、通胀与利率：费雪方程与泰勒规则
个体卖资产换现金所有人同时抛售 → 资产价格下跌一般均衡的价格反馈，第 30 章 · 期权、二叉树与蒙特卡洛：无套利定价的闭环

因此宏观不是微观公式的简单求和，而是在加总约束下重新求一个联立均衡。第二篇到此结束；第三篇开始处理时间、货币与总量核算。

§Python 建模实例

两市场一般均衡：超额需求、二分法与瓦尔拉斯法则

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
# 14-ge.py | 纯交换经济的均衡相对价格（只用标准库）
import math, random, statistics
random.seed(7)
# ---- 参数区 ----
ALPHA_A, ALPHA_B = 0.4, 0.7       # A 禀赋 (1,0)，B 禀赋 (0,1)
LO, HI, ITERS = 0.05, 5.0, 100
# ---- 超额需求：p1=1, r=p2/p1 ----
def demands(r):
    ma, mb = 1.0, r
    xa1, xa2 = ALPHA_A * ma / 1.0, (1 - ALPHA_A) * ma / r
    xb1, xb2 = ALPHA_B * mb / 1.0, (1 - ALPHA_B) * mb / r
    return xa1 + xb1 - 1.0, xa2 + xb2 - 1.0

def z1(r):
    return demands(r)[0]
# ---- 二分法求 z1=0 ----
lo, hi = LO, HI
for _ in range(ITERS):
    mid = (lo + hi) / 2
    if z1(mid) > 0:
        hi = mid
    else:
        lo = mid
r = (lo + hi) / 2
z_1, z_2 = demands(r)
# ---- 瓦尔拉斯法则：在非均衡价格处也恒成立 ----
test_r = 0.5
w1, w2 = demands(test_r)
walras = 1.0 * w1 + test_r * w2
# ---- 福利：贸易是否让双方都改善 ----
ua_before = 0.0                     # A 初始只有商品 1，x2=0
ma, mb = 1.0, r
xa1, xa2 = ALPHA_A * ma, (1 - ALPHA_A) * ma / r
xb1, xb2 = ALPHA_B * mb, (1 - ALPHA_B) * mb / r
ua_after = (xa1 ** ALPHA_A) * (xa2 ** (1 - ALPHA_A))
ub_after = (xb1 ** ALPHA_B) * (xb2 ** (1 - ALPHA_B))
# ---- 数值验证：打印可手算核对的量 ----
print("均衡相对价格 r=p2/p1=%.8f (解析解 6/7=%.8f)" % (r, 6 / 7))
print("均衡超额需求 z1=%.2e z2=%.2e (应为 0)" % (z_1, z_2))
print("A 消费=(%.6f, %.6f)  B 消费=(%.6f, %.6f)" % (xa1, xa2, xb1, xb2))
print("市场1总量=%.6f 市场2总量=%.6f (禀赋均为 1)" % (xa1 + xb1, xa2 + xb2))
print("瓦尔拉斯法则在 r=0.5 时 p·z=%.2e (恒为 0)" % walras)
print("贸易后效用 A=%.6f (贸易前 0) B=%.6f (贸易前 0)" % (ua_after, ub_after))

操作：把 ALPHA_A、ALPHA_B 改成相等的值，观察均衡相对价格是否变为 1。　预期与判读：均衡 r=6/7≈0.85714286；两市场超额需求均为 0；A 消费 (0.4,0.7)、B 消费 (0.6,0.3)；在非均衡价 r=0.5 处 p·z 仍为 0；贸易使双方效用从 0 变为正。

改参数看趋势：两个 α 越接近，均衡相对价格越接近 1；α_A 上升提高 A 对商品 1 的需求、压低 r。　文件位置：part2/14-general-equilibrium/code/14-ge.py

§常见误区

  • 把绝对价格水平当可求解变量：纯交换经济里只有相对价格可定，需固定计价物。
  • 以为 z₁=0 之后还要单独验证 z₂=0：由瓦尔拉斯法则自动成立（但数值误差需检查）。
  • 把代表性个体当成不需要论证的简化：加总超额需求的性质并不自动继承个体理性。
